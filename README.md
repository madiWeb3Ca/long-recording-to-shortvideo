# 长视频活动短片剪辑 · long-recording-to-shortvideo

**给不会剪片的人用的长录像剪辑工作台。**

讲座、工作坊、例会、比赛的长录像 → 经五道人工确认环节分段审核 → 剪成可发布短片。每环节只解决一类问题，确认后才进下一环；问题不跳层累积，避免成片后整体返工。

> A staged workflow that turns long event recordings into publishable short videos, with five human checkpoints so problems stop where they happen instead of stacking into a full rework.

---

## 解决什么问题

长录像直接一键出片，容易到最后才发现：选段跑偏、字幕折行、配乐抢人声、品牌口径错误——整片返工。

本工作流不追求电影级精剪，目标是**稳定达到可发布的合格成片**，同时让零基础用户看得懂每一步在审什么。

## 五道人工确认环节

| 环节 | 产物 | 审什么 |
|---|---|---|
| 第一步 · 需求与素材建档（P0） | 《成片需求单》 | 事实口径、授权、禁区、术语是否齐全准确 |
| 第二步 · 选段方案（P1） | 带时间码的结构单 | 该留的点在不在、废话删没删、主题是否完整 |
| 第三步 · 无包装粗样（P2） | 无包装拼接样片 | 段落衔接、节奏、总时长 |
| 第四步 · 包装成片（P3） | 第一版正式片 | 字幕断行、配乐音量、首尾片文案 |
| 第五步 · 金句切片（P4） | 60—90 秒独立切片 | 切片能否脱离上下文成立 |

串行推进：前一步未确认，不进入下一步。问题分层：选段问题留 P1，衔接问题留 P2，包装问题留 P3；不在包装阶段改画面结构，不在选段阶段讨论字幕样式。

## 三档流程（默认轻流程）

| 档位 | 用途 | 建档与包装深度 |
|---|---|---|
| `L1 内部回顾`（默认） | 会员群、内部回顾，不公开发布 | 极简建档 + 轻包装：可读字幕、隐私脱敏、不催单 |
| `L2 对外宣传` | 面向外部陌生人、报名意向的公开片 | 完整五步字段契约、首尾板、字幕、配乐与口径清理 |
| `L3 正式招募` | 招募、竞选、募资 | L2 基础上加授权逐项留档、品牌规范复核、可商用配乐 |

用途未指定时**默认落 L1**，不默认走全套重流程。档位升级必须由用户明确对外发布意图触发。

**各档不可省的底线**：出镜主体同意入片；隐私脱敏（他人隐私、敏感病情/经济/筹款金额、联系方式、未授权片段不上）；字幕可读；不催单、不留资、不放联系方式；不写未经核定的品牌口号与头衔。

## 关键做法

- **分段提示词**：每一步一段，只带本步骤所需输入，不把全部要求压进一条大提示词
- **事实不臆造**：缺失信息标 `{{待补}}`，按待补分级挂到对应步骤截止；品牌口径以官方规范为准
- **存疑自核**：语音、画面存疑不派用户听辨看片，由 AI 二次识别、抽帧、上下文比对处理；证据不足走保守降格
- **只读先行**：P0 可浏览画面与转写稿识别禁区，但不选段、不剪辑
- **垫乐自创**：由 AI 音频生成工具按片情自创纯音乐，不从曲库检索下载；人声优先、BGM 不压人声

```
long-recording-to-shortvideo/
├── SKILL.md

│   ├── prompt-p0-intake.md
│   ├── prompt-p1-selection.md
│   ├── prompt-p2-roughcut.md
│   ├── prompt-p3-packaging.md
│   └── prompt-p4-clips.md
├── references/                  # 字段契约、测试用例、取证规程、工具限制
└── scripts/
    └── selftest.py              # 字段覆盖、关键机制、契约一致性校验
```

## 自检

修改模板或契约后，运行：

```bash
python scripts/selftest.py
```

脚本校验字段覆盖、关键机制、契约一致性与测试样例断言；全部通过再进入下一步定稿。

## 边界与不做

- 不做逐帧精剪、电影感调色、多轨道特效
- 不替用户生成未经核定的品牌口号、头衔、活动信息
- 不默认素材可对外发布；授权不明挂风险，不进入可发布状态
- 不跳过人工确认环节直接出成片
