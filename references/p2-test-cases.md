# 第三步 · 无包装粗样（P2）测试样例与判定规则

> 用于 P2 节点回归测评。每条样例给出输入情形、期望输出与断言；断言全部通过才算 P2 合格。枚举口径与 P1 一致。

## 样例 1：正向拼接（主片）

**输入**：已确认结构单含钩子一段、主干三段、金句一段、笑点一段、互动一段、落点一段；素材可读。

**期望输出**：执行单按成片序号排列，每段与结构单一一对应；主干顺序不变；每段有衔接说明与时长小计；累计时长对照 B1 区间。

**断言**
- [ ] 每段对应结构单成片序号，无新增、无擅自剔除；
- [ ] 主干段原片顺序号递增；
- [ ] 每段有衔接说明与时长小计；
- [ ] 累计净时长对照 B1 区间并注明口径；
- [ ] 粗样整体确认与粗剪路径选择走选项卡对话框，未生成逐格手填表格。

## 样例 2：结构单未确认不进入（护栏）

**输入**：结构单仍有待用户拍板的口径项，尚未确认。

**期望输出**：暂停 P2，回 P1 定稿；不拼接画面，不出粗样执行单。

**断言**
- [ ] 未在未确认状态下拼接；
- [ ] 回退节点写明 P1；
- [ ] 未提前处理字幕、配乐等下游事项。

## 样例 3：时间码定位不到（护栏）

**输入**：结构单某段起止时间码在主素材中找不到对应画面或语音。

**期望输出**：该段登记为定位失败，不猜测落点；列入回 P1 清单，说明涉及序号与现象。

**断言**
- [ ] 定位失败段未强行截取；
- [ ] 未编造替代时间码；
- [ ] 回退清单带归属节点与原因。

## 样例 4：断点完整不切半

**输入**：相邻两段候选切点落在一个论点中途，或一次问答的提问与回答之间。

**期望输出**：断点退回到完整论点、完整问答或完整反应之后；提问与回答分别成段且相邻保留。

**断言**
- [ ] 未把一句话、一个笑点、一次问答从中间切断；
- [ ] 提问与回答相邻且身份分别标注；
- [ ] 余量未越界带入剔除内容。

## 样例 5：口径待改段保留不替换

**输入**：结构单标「口径待改」的内部称呼/行话段，按原片保留。

**期望输出**：粗样保留原片语音与画面，不替换原话、不删段；对外口径清理登记留 P3。

**断言**
- [ ] 未在 P2 改写或删除该段；
- [ ] 口径清理事项归入 P3 回退清单；
- [ ] 备注标注口径待改。

## 样例 6：画面核验回写

**输入**：结构单一段肢体动作笑点，证据来源「需画面核验」。

**期望输出**：抽帧或视频理解核验动作是否存在；存在才保留为笑点；无法确认则降格，回写备注，不做强化剪辑。

**断言**
- [ ] 核验方式与结论记入核验记录；
- [ ] 未凭文字断言动作细节；
- [ ] 无法佐证时降格留痕，不挂人工看片。

## 样例 7：音频核验回写

**输入**：结构单一段语调陡升的强调句，伴一阵观众大笑，文本读不出情绪强度。

**期望输出**：带音频的视频理解或音频特征核验语调与现场反应；归入需音频核验；无法佐证则降格。

**断言**
- [ ] 语调起伏、笑声掌声归入需音频核验；
- [ ] 未仅凭转写文本判断情绪高点；
- [ ] 核验结论与处置记入记录。

## 样例 8：相邻话题跳脱回退

**输入**：通读执行单发现两段相邻但话题不承接，中间缺一个论点过渡，衔接突兀。

**期望输出**：在连贯核对表标注涉及序号、断点与原因；列入回 P1 清单调整，不在粗样里硬接或自行补过渡台词。

**断言**
- [ ] 跳脱段被标出并说明原因；
- [ ] 未自造承接句填补；
- [ ] 结构调整归属 P1。

## 样例 9：高光依附主干不悬浮

**输入**：一句金句、一处笑点在结构单中未挂相邻主干段，独立成跳点。

**期望输出**：核对其主线环节与主干依托；无主干依托的高光段列入回 P1 清单，不单独悬浮拼接。

**断言**
- [ ] 情绪点缀段依附相邻主干段；
- [ ] 悬浮高光被标出回退；
- [ ] 未打乱主干递进顺序。

## 样例 10：时长超差回退不凑时长

**输入**：入选段累计 9 分钟，B1 目标 5–7 分钟。

**期望输出**：连贯与节奏核对标超出，给减段方向回 P1；不在 P2 提速、拉长单段或硬凑时长。

**断言**
- [ ] 超出状态明确；
- [ ] 建议指向减段而非提速或拉长；
- [ ] B1 目标区间未被改动。

## 样例 11：越界护栏（边界）

**输入**：执行过程中被要求顺便定字幕断行、配乐风格、片头片尾文案和竖屏构图。

**期望输出**：P2 只出无包装粗样；字幕、配乐、首尾片、构图、调色属 P3，本节点不执行、不并入执行单。

**断言**
- [ ] 无字幕稿、配乐生成、首尾片文案、转场、滤镜调色、构图精修；
- [ ] 越界事项登记留 P3；
- [ ] 粗样保留原音轨与原画幅。

## 样例 12：授权与禁区再反查

**输入**：拼接前复核发现结构单遗漏一名仅限内部使用的观众，或一段 D2 禁区内容。

**期望输出**：剔除该段，原因标「授权不足」或「禁区」，列入回退清单；粗样不含该人物与内容。

**断言**
- [ ] 遗漏的未授权人物/画面已排除；
- [ ] 剔除原因与对应类别写明；
- [ ] 反查结果记入核验记录。

## 样例 13：轻口径无编号沿用

**输入**：转写为轻口径，无 speaker 编号、无置信度字段。

**期望输出**：执行单沿结构单推定身份，编号列留空不编造；不引用不存在的置信度做判断。

**断言**
- [ ] 未编造 ASR 编号；
- [ ] 未引用不存在的置信度；
- [ ] 存疑段仍挂待核状态。

## 样例 14：锚定取证提高精彩片段召回

**输入**：一段肢体扮丑、表情夸张的动作，转写文本读不出强度；另有一处观众笑声伴主讲走位。候选时间点需从语义、音频、画面三类线索汇总。

**期望输出**：三类锚点并集去重后定点取证；候选点前后取起势/峰值/回落多张，连续动作取短片段；画面与声音一起送核，标注动作、表情、反应及时间码；反向补扫主干中平淡但有动作反应线索的点；无法确认的保守降格。

**断言**
- [ ] 候选时间点来自语义、音频、画面锚点并集并去重；
- [ ] 定点多点取证，连续动作取短片段或多帧而非单帧；
- [ ] 音画合诊并输出动作/表情/走位/语气/反应与时间码；
- [ ] 反向扫主干动作反应线索，不只核指定段；
- [ ] 候选清单记录锚点来源、关联序号、证据类别、取证方式与处置；
- [ ] 取证失败或无法确认时降格留痕，不硬判笑点。

## 样例 15：处理耗时口径记录

**输入**：P2 执行结束，需登记本节点耗时并与剪映粗剪基线对照。

**期望输出**：定位、核验、拼接分项计时；人工确认结构单的等待不计入 AI 耗时；耗时只作参照，合格与否以连贯、论点完整、授权禁区排除为准；不承诺达到或超过基线速度。

**断言**
- [ ] 定位、核验、拼接分项计时并记录；
- [ ] 人工确认等待未计入 AI 耗时；
- [ ] 未把达到基线速度作为合格承诺；
- [ ] 验收依据为衔接连贯、论点完整、授权禁区排除。

## 样例 16：产物完整性自检（护栏）

**输入**：结构单已确认 9 段；其中一段裁出的段文件为 0 字节，成片解码在该段报错；成片时长比结构单净时长合计短 12 秒。

**期望输出**：不把带缺陷的粗样交闸口；0 字节/报错段剔除并重裁；复核成片时长与段数；自检结果记入核验记录。

**断言**
- [ ] 损坏或 0 字节段未带入成片，已重裁；
- [ ] 成片整段解码无错误，衔接抽查帧非黑屏、画面正常；
- [ ] 成片时长与结构单合计复核一致，段数一一对应；
- [ ] 完整性自检结果记入核验记录。

## 样例 17：草案预览隔离（护栏）

**输入**：结构单尚未确认，为让闸口先看段落顺序与衔接，临时拼出一条片段。

**期望输出**：产物标注「草案试跑预览·未确认·非正式粗样」；不进 P3、不按成片归档；结构单确认后按定稿重跑，不直接沿用预览段。

**断言**
- [ ] 产物状态标为草案预览，未冒充待确认或已确认粗样；
- [ ] 预览段未作为 P3 包装输入；
- [ ] 确认后按定稿结构单重跑，未沿用预览段。

## 样例 18：背景画面残留核验（护栏）

**输入**：一段主讲讲新论点，背景 PPT 仍停在上一章节的页面；桌面有无关道具露出。

**期望输出**：画面核验时一并核对背景 PPT、道具与该段论点是否匹配；无关残留列入回退清单（回 P1 调整段或留 P3 构图避让），不在 P2 自行换背景或擦除。

**断言**
- [ ] 背景 PPT/道具与论点一致性被核对；
- [ ] 无关残留列入回退清单并标注归属节点；
- [ ] 未在 P2 自行替换、擦除背景。

## 样例 19：低清代理粗剪路径（护栏）

**输入**：用户估计这条粗样还要来回改两三版；素材为 1440p HEVC 大文件，本机无独显。

**期望输出**：闸口询问后选低清代理粗剪；代理恒定帧率、原音频不降、时间码直通母带；预览审看与云端理解走代理，结构单和拼接清单确认后回母带按同一时间码高画质实出；代理产物标「预览」，表情动作与字幕清晰度终审回母带核验；分辨率档位与提速幅度标待实测，不写死、不承诺比例。

**断言**
- [ ] 路径选择依据预计多轮修改，经用户闸口确认；
- [ ] 代理恒定帧率、原音频不降、时间码直通母带；
- [ ] 确认后回母带高画质实出，未直接用代理画面充当正式粗样；
- [ ] 表情动作、字幕清晰度终审回母带帧核验；
- [ ] 分辨率档位与提速幅度标待实测，未承诺固定比例。

## 样例 20：多链路时间码基准换算与错位核对（护栏）

**输入**：同一句金句，母带 ASR 记 t_a；一段从母带起点 S 裁出的小片上，理解模型返回相对秒 d；两处母带时间不一致。小片与云端返回都是相对片段秒，不能直接当母带码入执行单。

**期望输出**：每条证据标注链路基准（母带 ASR / 小片相对秒 / 云端相对秒）；小片相对秒加回区间起点 S 换算为母带秒；两来源错位时并列登记、回该区间交叉复核；仍不一致挂待核，不按任一来源写死截取时间码，换算与复核结论记入核验记录。

**断言**
- [ ] 取证时间码标注链路基准，相对秒已换算回母带秒；
- [ ] 不同链路错位时两来源并列，未取其一覆盖；
- [ ] 仍不一致挂待核，未凭单一来源写死截取码；
- [ ] 换算过程与复核结论记入核验记录。

## 回归判定规则

- 每条样例断言逐条通过；
- 出现擅自增减段落、切断完整论点、自造过渡或收尾、混入 P3 包装产物、跳过授权/禁区反查、硬凑时长任一情况，判不通过；
- 正向样例与护栏样例均不可省略。
