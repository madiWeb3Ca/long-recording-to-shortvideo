## 2. 枚举值

### 成片用途档位（F0）

- `L1 内部回顾`：会员群/内部回顾，不公开发布；默认档。建档与包装从简，底线不减免。
- `L2 对外宣传`：面向外部陌生人或报名意向的公开片；走完整五节点字段契约。
- `L3 正式招募`：招募/竞选/募资等正式对外片；在 L2 基础上加授权留档、品牌复核、可商用配乐与发布前台账。
- 档位推定：B1=`内部回顾版`、B2=`本组织会员`、B3=`纯内部回顾` → L1；B1=`主片`/`短切片` 且 B2=`外部陌生人`/`报名意向用户` → L2；招募竞选募资类 → L3。用途与观众缺失时不代填对外口径，默认落 L1 并标注「采用默认」。
- L2/L3 边界：L2 对外宣传以「让外部陌生人了解主题、记住嘉宾或观点」为目的，可含活动信息介绍，但不承担直接转化职能；L3 正式招募以「报名入会、竞选拉票、募资筹款」等转化为直接目的，片内承担号召动作。交界场景按主要目的定档：期望动作是了解主题/记住人归 L2；期望动作是报名入会/竞选/募资且片内有号召职能归 L3。同一素材两种用途并存时，按主要目的定一档；两类目的都要交付，分别建档、不混用一套口径。

### 成片形态与目标时长（B1）
- `主片`：5–7 分钟，讲透一个完整主题。
- `短切片`：60–90 秒，单句强观点，可独立转发。
- `内部回顾版`：面向本组织会员的回顾。
- 可组合：`主目标 + 派生切片`；派生切片沿用主片口径，独立口径留到 P4。

### 目标观众（B2）
- `外部陌生人`：没来过本组织、不认识主讲人。
- `本组织会员`：已了解组织背景与角色。
- `报名意向用户`：接触过活动信息、有到场可能。

### 希望观众看完做什么（B3）
- `了解主题` / `记住主讲人` / `报名下一场` / `纯内部回顾`。

### 发布平台与画面比例（B4）枚举
- `9:16 竖屏`：小红书 / 抖音 / 视频号竖版；未指定走默认 `9:16 竖屏`。
- `16:9 横屏`：B 站 / 视频号横版 / YouTube 等横版渠道。
- `其他比例（自填）`：1:1 方形或平台特殊比例，注明平台与具体比例。
- 多平台分发时逐项登记平台与对应画幅；切片渠道画幅在同一清单中注明，未注明的切片沿用主片 B4。

### 观众与内容是否匹配（B5）错位组合
| 观众 | 动作 | 判定 |
|---|---|---|
| 外部陌生人 | 报名下一场 | 错位：外部片不做催单 |
| 外部陌生人 | 纯内部回顾 | 错位：口径不可混用 |
| 报名意向用户 | 纯内部回顾 | 错位：对象与内容不一致 |
| 任意观众 | 了解主题 | 匹配 |

### 授权（A5）枚举
- `已授权对外` / `仅限内部` / `未确认` / `明确拒绝`。
- `明确拒绝` 触发停止分支；`未确认` 挂风险，不进入可发布状态。
- A5-1 按主体逐个登记：主讲人 / 出镜嘉宾 / 出镜观众；状态与主体一一对应。
- A5-3 配乐：由 P3 用 AI 音频生成工具按片情自创垫乐（文生 WAV），不从既有曲库检索或下载曲目；P0 只登记曲风与人声形态偏好，不走授权枚举与公开传播核实。

### C 首尾片方式枚举
- C1-模式 片头方式：`默认片头` / `首句导入` / `无片头`；未指定走默认 `默认片头`。
  - `默认片头`：生成独立片头板，按活动名 / 主标题 / 身份行三行逐字排版；
  - `首句导入`：不生成独立片头板，在主片开头约 5 秒内叠加一句取自 C1 的导入句（字幕条或开场口播导入），点出主题或受访人身份；导入句一行，停留以读完为准，不留片头静音段；
  - `无片头`：不生成片头板，主片直接起，C1 文案免采集。
- C2-模式 片尾方式：`默认尾片` / `自备尾片模板` / `无片尾`；未指定走默认 `默认尾片`。
- 选自备尾片模板：登记模板文件来源、版本与版式；P3 沿用模板版式与文案结构，只做竖屏适配，不擅自改写模板文案；模板未提供或不可用时回退默认尾片。

### C3 切片板位方式枚举
- 仅当 B1 成片目标含派生切片时登记；纯主片目标下该字段记 `无板`，免采集 C3。
- C3-模式 切片板位方式：`无板` / `标题板` / `标题板+尾片`；未指定走默认 `无板`。
- `无板`：切片不加标题板、不加尾片，开场钩子与落点计入 60–90 秒净时长。
- `标题板`：仅加一行切片标题板，不加组织尾片；标题取自 C3，只概括本切片实际内容。
- `标题板+尾片`：标题板外加切片尾片；尾片组织标识与引导语沿用 C2 封存口径，不催单、不留资、不放联系方式；选用自备尾片模板时登记模板来源、版本与版式，规则同 C2-模式自备分支。
- C3 切片标题文案仅在 `标题板` / `标题板+尾片` 时采集；`无板` 时免采集，P4 不临时拟写切片标题。

### 转写状态（A4）
- `已有逐字稿` / `待转写`；待转写登记责任人与截止节点（P1 开始前），缺稿阻塞 P1。
- 转写执行路径（提速口径）：优先用 ffmpeg 抽取单声道 16kHz 音频（m4a/mp3），以 audio_url 提交 ASR，避免整段上传大体积视频；仅在无独立音频轨时用 video_url。
- 转写口径：默认**轻口径**（不开说话人分离、不开逐句置信度），对齐客户端字幕提取速度；重口径（开分离 + 置信度）作为可选增强，仅当需要说话人归属清单或自动低置信筛查时启用。说话人编号在轻口径下不存在，身份由 P1 结合上下文推定。

### 自带字幕与水印（A6）
- `无硬字幕无水印`；`自带烧录中文字幕`（登记位置、样式、清晰度、是否遮挡主体）；`带画面水印`（台标/logo/二维码/角标，登记位置与避让或模糊需求）；两类可组合登记。
- 字幕处理裁决：P3 拟用字幕与原片烧录字幕在位置、样式、断行上基本一致时，沿用原字幕、不擦除重压；需关键字放大、换字体颜色位置、重新断行或重排时，再评估擦除原字幕后重压。水印避让方案单独登记，不并入字幕决策。

### 日期时段来源（A3）
- `用户直述` / `物料旁证`；旁证须经用户确认转已确认，否则挂待补。

### 2.2 档位裁剪表

| P3 包装 | 可读字幕；可无品牌首尾板或仅极简身份条；默认无 BGM；logo/口号/配乐版权复核可省 | 全套首尾板、字幕、配乐、口径清理 | 全套 + 品牌规范复核 + 生成曲可商用授权发布前闭合 + 发布前复核台账 |

### 2.3 L3 正式招募留档清单

L3 在 L2 全套契约之上，以下各项必须逐项登记、可追溯；未闭合项不进入可发布状态：

| 类别 | 留档要求 |
|---|---|
| 人物授权（A5-1） | 主讲人、每位出镜嘉宾、出镜观众分别登记状态与授权范围（仅限内部 / 可对外 / 可公开发布），不合并成一条「已授权」；`未确认` 主体不进招募片 |
| 画面素材授权（A5-2） | PPT、照片、引用影像、现场物料分别登记来源与授权状态；无规范授权的素材该位留空，不截取翻拍 |
| 品牌规范 | 组织全称、slogan、logo 文件版本与用法、头衔口径，以官方品牌规范核定；规范未覆盖的写法标「待品牌复核」，不自行推测沿用旧版 |
| 配乐授权（A5-3） | AI 生成曲的可商用/公开传播授权类型在发布前闭合登记；不允许带未核可商用状态上线；生成提示词、曲风、配器、电平与机检日志一并留档 |
| 发布前复核台账 | 逐项列：复核项、当前状态、责任人、截止节点；授权、品牌口径、对外脱敏、隐私边界四项全部闭合后才可标可发布 |

**各档不可减免底线**：出镜主体同意入片；隐私脱敏（他人隐私、敏感病情/经济/筹款金额、联系方式、未授权片段不上）；字幕达可读下限；不催单、不留资、不放联系方式；不写未经核定的品牌口号与头衔。

### 2.1 提问形态（选项卡）

P0 补问分两种形态，禁止把枚举字段开放成一句话追问：

- **单选选项卡（互斥）**：B1 成片目标、B2 目标观众、B4 平台画幅、A4 转写状态、A5-1/2/3 各主体与素材授权状态、A5-4 是否有禁录段落、C1 片头标题倾向、C1-模式 片头方式、C2-模式 片尾方式、C3-模式 切片板位方式。一题一卡，只能选一项。
- **多选选项卡（可叠加）**：B3 期望动作、D1 保留清单类型、A5-2 画面素材类别、多平台清单。一题一卡，可选多项。
- **自由文本**：A2 姓名头衔、A3 活动全称/日期/城市、C2 片尾组织名/口号/引导语、C3 切片标题文案（仅标题板类模式采集）、D1/D2 条目描述、D3 术语表；不套固定选项，提问时给格式要求与示例，按原话登记不代拟。

选项卡要素：题干、枚举选项、默认项（仅 B4 等规则允许的客观默认）、不填影响的下游环节、兜底「其他（自填）」。选「其他（自填）」才接收自由文本；两轮无答复按待补分级挂风险。

## 3. 口径裁决表

| 冲突类型 | 第一优先 | 第二优先 | 第三优先 | 冲突处理 |
|---|---|---|---|---|
| 品牌口径 | 官方品牌规范 | 用户书面确认文案 | 临时口述 | 以规范为准；冲突列入待确认 |
| 观众口径 | 所选发布版本的可读口径 | — | — | 对外片排除内部称呼；内部片可保留 |
| 素材版本 | 主素材 | 辅助片段 | — | 时间码以主素材为准 |
| 说法一致性 | 素材原话 | 用户口述 | 模型推测 | 不一致时以原话为准并请用户复核 |

## 4. 停止分支触发条件

### 主体不可用（停止，不生成需求单）
1. 素材无法读取、无声、画面不可用，且无替代版本。
2. 主体出镜者或主体段落明确拒绝对外发布。
3. 素材含未公开敏感信息，且用户无法划定可用范围。
4. 授权状态为 `明确拒绝` 且该内容为成片主体。

### 局部不可用（继续建档，记入 D2）
1. 仅某位观众、某段发言、某段画面被拒绝或未授权。
2. 该主体/段落记入禁区清单，其余素材继续采集；是否影响成片目标列入待确认。

停止时输出：受阻原因、缺失项、继续所需材料；不生成需求单，不进入 P1。

## 5.1 素材主副本判定优先级

完整度 > 清晰度 > 收音 > 机位覆盖；判定理由写入 A1。辅助片段不反向覆盖主素材时间码。

### 5.1-ter 多段分段素材口径

一场活动由多段独立文件组成（分段拍摄、中途停顿）时，按以下口径建档：
- A1 逐段登记：文件名、时长、各自技术状态、拍摄顺序；每段时间码从该段 0 点起算，不假设段间首尾相接、不假设间隔为 0；
- 段与段之间可能有数分钟空档，空档内容不补造、不推断为连续发言；
- 段序以需求单核定的场次/内容顺序为准，不按文件名编号或字母序推断；段序存疑列入待确认；
- 选段与时间码映射标注来源段；跨段衔接只保留内容承接，不拼接拍摄空档。

## 5.1-bis 技术元数据探测（P0 开工先做）

- 开工先探测并登记：容器/编码、存储分辨率、显示旋转矩阵（Display Matrix rotation）、帧率、音轨采样率/声道/码率；存储分辨率与应用旋转后的显示方向分列登记。
- B4 画幅与 P3 构图以探测出的显示方向为准，不凭缩略图、文件名或目测归向；探测不到旋转信息标待复核，不擅自判横竖屏。
- 探测工具受限（无 ffprobe 等）时用可用的媒体探测途径解析，结论注明取得方式；旁证结论标待复核。

## 5.2 封存后变更回滚

- 口径变更必须回本节点升版留痕；
- 登记：变更字段、差异内容、受影响下游节点、已产出产物是否作废重跑；
- 禁止在 P1–P4 口头改口径。

## 6. 需求单版本元信息

每份需求单头部必须包含：
- 版本号（初始 `v1`，变更升版）；
- 生成时间；
- 确认状态：`草稿 / 已确认 / 已变更`；
- 最近变更项说明。

口径变更必须升版并留痕，禁止在后续节点口头改口径。
