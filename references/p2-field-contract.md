# 第三步 · 无包装粗样（P2）字段契约与判定规则

> 配套 `assets/prompt-p2-roughcut.md`（v1.4）。本文件定义粗样执行单字段、截取衔接规则、核验回写、连贯校验与回退分层，供 Skill 实现与测评核对使用。枚举口径与第二步（P1）结构单保持一致。要素通俗名对照见 SKILL 总纲对照表。

## 1. 输入前置条件

| 输入 | 来源 | 缺失处理 |
|---|---|---|
| 已确认第二步（P1）结构单 | 第二步人工确认环节确认 | 未确认回 P1，不进入 P2 |
| 锁定需求单 | 第一步（P0） | B1 时长、B2 观众、B4 画幅、A5 授权、D2 禁区、C 组文案（只记录不执行） |
| 主素材 | P0 登记 | 不可读回 P0/P1 标注，不硬拼 |
| 转写稿 | P1 预处理产物 | 定位与衔接核对用；缺失段按 P1 待核状态沿用 |

## 2. 前置校验与回退分支

| 情形 | 处置 |
|---|---|
| 结构单未确认、仍有待拍板项 | 回 P1 定稿后再来；仅可出标注清晰的草案试跑预览（见 §2.1），不出待确认粗样 |
| 时间码在素材定位不到 | 登记该段，不猜落点，列入回 P1 清单 |
| 素材人声/画面不可读 | 回 P0/P1 标注，不强行出粗样 |
| 主干段落缺失或转写不可用 | 沿用 P1 降级结论，不在 P2 硬拼 |

### 2.1 产物状态与隔离

| 状态 | 触发条件 | 用途与隔离 |
|---|---|---|
| 草案试跑预览 | 结构单未确认，仅为供人工确认环节审看顺序与衔接临时拼出 | 必须显式标注「草案·未确认·非正式粗样」；不进 P3，不作为包装输入；命名与正式粗样区分 |
| 待确认粗样 | 结构单已确认，P2 拼接与核验完成，待人工确认环节审看 | 人工确认环节审看对象；未确认前不进 P3 |
| 已确认粗样 | 人工确认环节确认衔接与节奏 | 进入 P3 包装的输入 |

- 草案预览不得按「粗样成片」归档；其段时间码与核验结论回挂草案结构单，结构单确认后须按定稿结构单重跑，不直接沿用预览段。

### 2.2 粗剪路径选择（出预览前人工确认环节确认）

出预览粗样前，以单选选项卡向用户确认预计改稿轮次与粗剪路径（母带直出 / 低清代理粗剪），卡片含后果说明与兜底「其他（自填）」；按结果选路径：

| 路径 | 触发条件 | 做法与隔离 |
|---|---|---|
| 母带直出 | 预计一轮定稿，或对预览画质要求高 | 按主素材母带规格裁剪出粗样 |
| 低清代理粗剪 | 预计需多轮修改、反复预览 | 先生成低清代理（恒定帧率、原音频不降、时间码直通）；选段核对、预览审看、云端理解抽帧走代理；结构单与拼接清单确认后，回母带按同一套时间码高画质实出；代理产物标「预览」，不冒充正式粗样画质 |

代理护栏：
- 代理只用于定结构、顺序与衔接；表情动作、字幕清晰度的终审回母带帧核验，不只信代理画面；
- 代理分辨率、编码规格与提速幅度以当前环境实测为准；未实测前不写死分辨率档位、不承诺提速比例；
- 代理与母带时间码必须一一对应；代理转码丢帧或帧率不稳时，不得回贴母带重裁；
- 降画质不降音频，人声与笑声轨道保持原样；
- 路径选择与结果记入核验记录。

## 3. 粗样执行单字段定义

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 粗样序号 | 整数 | 是 | 按拼接顺序排列 |
| 结构单成片序号 | 整数 | 是 | 与 P1 结构单一一对应，无新增、无擅自剔除 |
| 原片顺序号 | 整数 | 是 | 该段在原片中的先后；主干段递增 |
| 截取时间码 | 时间区间 | 是 | `MM:SS–MM:SS`，以主素材为准；含前后 0.3–0.5 秒余量；辅助片段注明来源 |
| 推定身份 | 枚举 | 是 | 主讲人 / 嘉宾 / 观众 / 不明；沿用 P1 映射 |
| 主角色 | 枚举 | 是 | 钩子 / 主干 / 金句 / 笑点 / 互动 / 落点；沿用 P1 |
| 衔接说明 | 文本 | 是 | 与上一段如何承接：问答相邻 / 主干递进 / 案例佐证 / 笑点反应 / 落点收尾等 |
| 时长小计 | 时长 | 是 | 口播按说话时长，互动按时间码跨度 |
| 备注 | 文本 | 否 | 需画面核验 / 需音频核验 / 转写待核 / 低置信 / 授权待核 / 术语待核 / 轻口径无编号 / 重口径分离失败 / 口径待改 |

- ASR 编号不在执行单重复登记；需要时沿结构单留空或附编号，轻口径不补。
- 证据来源沿用 P1 枚举：文字可证 / 需画面核验 / 需音频核验。

## 4. 截取与衔接规则

1. 顺序：严格按结构单成片序号；主干保持原片递进，钩子开头、落点收尾，不调换叙事先后。
2. 余量：起止码前后各留 0.3–0.5 秒；余量碰到相邻保留段或禁区段时收紧到语义边界，不带入剔除内容。
3. 断点完整：落在完整论点、完整问答、完整反应之后；不切断一句话、一个笑点、一次问答。
4. 衔接：段间硬切，不加转场；提问与回答相邻；笑点、互动保留自然呼吸；主讲与观众发言不粘在同一段。
5. 归属：发言归对应身份，笑声掌声附和计入互动段备注；未现场发言的被引人物不进标注。
6. 口径待改段：按原片语音画面保留，不替换原话、不删段；对外口径清理留 P3。
7. 画幅：粗样保持主素材原画幅；B4 只记录，竖屏裁切、主体居中、安全区留 P3。

## 5. 核验回写

| 证据来源 | 核验方式 | 无法佐证处置 |
|---|---|---|
| 需画面核验 | 抽帧 / 视频理解，核表情、肢体、走位、画面反应；同时核背景 PPT、道具、画面残留是否与该段论点匹配 | 降格为不作为笑点/反应依据，回写备注，不做强化剪辑；背景残留无关画面列入回 P1/P3 清单 |
| 需音频核验 | 带音频的视频理解 / 音频特征，核语调起伏、重音停顿、笑声掌声、现场反应声 | 同上，不凭文本断言情绪高点 |
| 转写待核/低置信/术语待核 | AI 二次识别或上下文比对 | 占位保留并挂待核状态，不凭存疑文本写理由，也不擅自删掉 |

- 执行前对照 D2 禁区与 A5 授权再反查；遗漏的未授权人物、画面素材或禁区内容剔除，原因标「授权不足」或「禁区」，列入回退清单。

### 取证策略（提高精彩片段召回，不依赖单纯加密抽帧）

1. **锚定触发取帧**：先汇总三类候选时间点，取并集去重后定点取证，不做全片均匀密采：
   - 语义锚点：转写稿金句、反问、点名人物、案例段、明显停顿句；
   - 音频锚点：笑声、掌声、惊呼、语调陡升、重音、突然停顿；
   - 画面锚点：镜头切换、景别变化、动作幅度变化。
2. **定点多帧**：每个候选点前后 ±0.5–1 秒取起势、峰值、回落多张；肢体/表情连续过程优先取 0.5–1 秒短片段，不只取单张静态帧。
3. **分层采样**：先粗筛定位候选区间，只对候选段加密取证；普通主干段用低档，控制废帧与耗时。
4. **音画合诊**：候选段画面与声音一起送理解模型，同时标注动作、表情、走位、语气起伏、现场反应及对应时间码；纯听觉信号走音频通道，不靠帧推断。
5. **双向回查**：正向核 P1 标出的需核验段；反向扫主干中转写平淡但有动作/反应线索的点（设问后停顿、案例前后、语气转强），补入候选清单。
6. **指令显式要标签**：理解任务要求输出表情、肢体动作、走位、语气、反应与时间码，不只概括内容；锚点漏掉、取证失败或模型无法确认的，保守降格，不硬判为笑点或反应。
7. **时间码链路基准**：每条取证时间码标注来源链路基准——母带 ASR / 裁切小片相对秒 / 云端理解返回相对秒；小片与云端相对秒必须加回区间起点换算回母带秒后，才写入执行单截取时间码。同一锚点在不同链路返回的时间码不一致时，并列两来源与各自时间码，回该区间交叉复核定位；仍不一致则挂「待核」，不按任一来源写死截取时间码，复核结论记入核验记录。

> 锚点清单生成、取帧方式选型、合诊配置与回写字段的执行细则见 `references/p2-evidence-protocol.md`。

## 6. 连贯与节奏规则

1. 主线对照：每段沿 P1 结构单的主线环节定位；金句、笑点、互动依附相邻主干段，不悬浮成跳点。
2. 同论点相邻：同一话题段落排在一起，其他论点不插入打断。
3. 首尾呼应：开场钩子抛出的问题或矛盾，收尾落点能回应；脱节列入回 P1 清单。
4. 通读校验：按成片序号通读各段内容摘要，查相邻段话题承接、论点完整、有无跳跃或悬浮高光；突兀处标注序号、断点与原因。
5. 节奏：拖沓、衔接跳脱、笑点缺铺垫等记入核对表；是否改段回 P1 定。

## 7. 时长口径

- 口播段按说话时长，互动段（提问、附和、笑声、鼓掌留白）按时间码跨度计入；
- 不含转场、字幕停留、首尾片包装；
- 对照 B1 目标区间；超出或不足只给减段/补段建议回 P1，不提速、不拉长单段、不硬凑时长。
- 粗样累计净时长仍超/不足的，回 P1 挂账闭环并在核验记录登记状态；用户放宽区间须回 P0 改口径留痕；未闭账不进 P3 包装。

## 7.1 处理耗时与基线

- 记录 P2 各步 AI 处理耗时：段落定位、画面/音频核验、拼接导出；人工确认结构单的等待时间不计入 AI 耗时。
- 参照口径：客户端口播智能粗剪是自动选段 + 粗剪拼接一体；本流程 P1 选段与 P2 拼接分列，对比耗时须注明口径；具体基线数值由当前素材与执行环境实测后登记，规则层不预设承诺值。
- 耗时只作参照，不作为必须达到或超过的承诺；验收以衔接连贯、论点完整、授权禁区排除为准，不以耗时长短论合格。
- 云端排队、上传、处理三段耗时分别记录；工具能力受执行环境限制，未实测的召回率与耗时标注为待验证。

## 8. 问题回退分层（不跨层处理）

| 问题类型 | 归属步骤 |
|---|---|
| 选段取舍、时间码定位、授权/禁区遗漏、段数时长超差、连贯结构问题 | 回 P1 |
| 字幕断行、配乐、首尾片文案与品牌排版、竖屏构图、调色 | 留 P3 |
| 独立切片派生 | 主片定稿后留 P4 |

## 9. 第三步（P2）完成判定（人工确认环节）

粗样执行单必须满足：
- [ ] 每段与结构单一一对应，顺序一致，无新增、无擅自剔除；
- [ ] 时间码起 < 止、可在素材定位、余量合规，断点未切断完整论点与问答；
- [ ] 累计净时长对照 B1；超差或不足只给回 P1 建议，不凑时长；
- [ ] 相邻段承接连贯，高光段有主干依托，首尾呼应，无悬浮跳点；
- [ ] 需画面/音频核验段已由 AI 核验并回写结论；无法佐证的高点已降格留痕；
- [ ] 输出不含字幕稿、配乐生成、片头片尾文案、转场、滤镜调色、构图精修等 P3 产物；
- [ ] 问题按节点回退，待核与待确认项带归属节点和截止节点。

用户确认粗样后才进入 P3；未确认不做包装。

### 9.2 档位裁剪（按 F0）

| 核验产出 | L1 内部回顾 | L2 对外宣传 | L3 正式招募 |
|---|---|---|---|
| 核验记录 | 从简：标注衔接与节奏结论，需核验段给结论即可 | 完整取证规程，锚点取证与回写逐项登记 | 完整取证 + 多点音画合诊，证据等级与核验结论逐条可追溯 |
| 取证档位 | 普通主干低档粗扫，候选高点定点核验 | 按 §5 锚定触发取帧、定点多帧 | 候选段加密取证，画面与声音合诊，双向回查 |
| 授权反查 | 本人内部使用同意已登记即可 | 按主体逐项反查，未授权剔除 | 按主体逐项反查，授权存疑段回 P0/P1 补核，不带入粗样 |

- 三档共同底线不变：断点完整、衔接连贯、时间码可核对、无法佐证的高点降格留痕、产物完整性自检，不因 L1 从简免除。

### 9.1 确认环节引导形态

- 粗样整体确认、路径选择与回退取舍沿用全局选项卡对话框形态：单选/多选按互斥或叠加选择，卡片含选项、客观默认、后果与兜底「其他（自填）」；不生成逐格手填表格；语音与画面存疑由 AI 自核，不进确认环节对话框。

### 9.3 产物完整性自检（拼接后、移交人工确认环节前）

- 逐段检查段文件非空、可解码；0 字节、损坏或解码报错的段剔除并重裁，不带入成片；
- 成片整段解码检测无错误；抽查段间衔接帧非黑屏、人物与画面正常；
- 成片累计时长与结构单净时长合计复核一致；段数与结构单一一对应，无遗漏、无多余段；
- 本地拼接时各段编码参数（分辨率、帧率、音频参数）统一后再合并；参数不一致先重编码统一，不直接流复制；预览降规格须在产物状态与备注中标明，不冒充正式粗样画质；
- 自检结果记入核验记录；任一项不通过，回退到对应段重裁或重拼，不把带缺陷的粗样交人工确认环节。
