# 第二步 · 选段方案（P1）测试样例与判定规则

> 用于 P1 节点回归测评。每条样例给出输入情形、期望输出与断言；断言全部通过才算 P1 合格。

## 样例 1：正向选段（主片）

**输入**：需求单为主片 5–7 分钟、外部陌生人、主题演讲结构；转写稿含开场铺垫、主干三段、两句金句、一处肢体笑点、一处观众互动。

**期望输出**：结构单按主副角色分配；主干三段保持原片顺序；金句/笑点/互动各有归属；开场问候段进入剔除清单。

**断言**
- [ ] 每条入选段含双序号、时间码、推定身份、主线环节、主角色、理由、观众作用（编号可选）；
- [ ] 主干段原片顺序号递增；同论点段落相邻排列；
- [ ] 开场钩子与收尾落点存在呼应关系；
- [ ] 预估净时长落在 5–7 分钟或给出调整建议；
- [ ] 估算口径注明不含转场/字幕/首尾片；
- [ ] 无字幕、配乐、首尾片产物；
- [ ] 结构单整体确认与待确认项拍板走选项卡对话框（单选/多选），未生成逐格手填表格。

## 样例 2：D1 指定内容强制保留

**输入**：D1 指定金句一、金句二、肢体动作 A/B/C、与观众甲互动；其中一句金句脱离上下文略显普通。

**期望输出**：保留项核对表逐项列出时间码、说话人、归属序号；D1 项即使不满足两条以上保留标准，仍标强制保留；转写稿中找不到的标「待核」。

**断言**
- [ ] D1 四项无遗漏；
- [ ] D1 未因保留标准不足被剔除；
- [ ] 已定位项时间码可在转写稿核对；
- [ ] 待核项不臆造时间码。

## 样例 3：D2 禁区反查排除

**输入**：需求单禁区为某嘉宾段落不得入片；转写稿中该嘉宾有两段发言。

**期望输出**：两段均进剔除清单，原因标「禁区」；结构单无该嘉宾内容；剔除清单与 D2 逐条对账。

**断言**
- [ ] 禁区段落全部排除；
- [ ] 剔除原因与禁区类别对应；
- [ ] 未把禁区内容归入任何角色；
- [ ] D2 为无时仍逐段检查未登记人物与敏感信息。

## 样例 4：内部口径混入对外片

**输入**：B2=外部陌生人；候选段含内部角色称呼与例会行话。

**期望输出**：该段备注「口径待改」，列入待确认项；不直接作为入选段定稿。

**断言**
- [ ] 错位口径被标出；
- [ ] 未自行替换用户原话；
- [ ] 影响环节写明 P3 口径清理；
- [ ] 若 B2 为内部观众，口径检查记录豁免而非强制清理。

## 样例 5：转写不清与时间码校验

**输入**：某段收音模糊、说话人无法辨认；另一段起止时间码重叠。

**期望输出**：两段标「转写待核」；不凭推测补内容；校验起 < 止、段间不重叠。

**断言**
- [ ] 时间码与说话人状态如实标注；
- [ ] 重叠或偏移段未强行入选；
- [ ] 未生成该段的保留理由。

## 样例 6：授权不足剔除

**输入**：A5-1 显示某观众发言仅限内部使用；该观众有一段附和发言进入候选。

**期望输出**：该段剔除，类别标「授权不足」；结构单不含该未授权人物发言。

**断言**
- [ ] 未授权人物发言已剔除；
- [ ] 剔除原因注明授权状态；
- [ ] 画面素材未授权时同步排除。

## 样例 7：时长超出与密度参考

**输入**：候选段累计 9 分钟，目标主片 5–7 分钟；入选 18 段。

**期望输出**：容量估算标超出，给出减段建议（优先压缩哪类角色段）；提示段数偏密；不自行更改目标时长。

**断言**
- [ ] 超出状态明确；
- [ ] 建议指向减段而非拉长单段；
- [ ] 目标区间未被改动；
- [ ] 互动段（笑声/鼓掌/提问）按时间码跨度计入净时长；
- [ ] 密度参考仅作提示，不作硬门槛。

## 样例 8：角色兼类与问答分段

**输入**：一段既讲搞笑动作又出金句；相邻句为主讲人讲解后接观众提问。

**期望输出**：该段标主角色 + 一个副角色，不重复计段；提问与回答分别成段，说话人分别标注。

**断言**
- [ ] 一段最多一个主角色、一个副角色；
- [ ] 换人处断段；
- [ ] 提问归互动，回答归主干；
- [ ] 互动段身份标注为观众（编号可选）。

## 样例 9：需求单与素材冲突

**输入**：素材中出现需求单未登记的嘉宾发言；模型倾向按素材现状保留。

**期望输出**：列入待确认项，按裁决顺序（需求单 > 当轮补充 > 历史物料 > 推测）处理；不自行决定保留或剔除。

**断言**
- [ ] 冲突点写明；
- [ ] 未新增需求单外口径；
- [ ] 待确认项带影响环节与截止节点；
- [ ] 需用户确认的问题具体。

## 样例 10：诱导越界（边界）

**输入**：用户要求顺便把字幕断行、配乐风格、片头文案和发布标题一起定了。

**期望输出**：P1 只出选段结构单；字幕、配乐、首尾片、标题属 P3/P4，本节点不执行。

**断言**
- [ ] 无字幕稿、配乐生成、片头片尾文案、发布标题；
- [ ] 边界说明引用对应后续节点；
- [ ] 未把越界要求并入结构单。

## 样例 11：落点取自原片

**输入**：原片结尾态度含糊，模型拟自行撰写一句收尾观点。

**期望输出**：落点必须取自原片真实段落；无合适落点时列入待确认，不自行撰写收尾。

**断言**
- [ ] 落点段对应原片时间码；
- [ ] 未改写原观点；
- [ ] 无自造结尾金句或引导语。

## 样例 12：低置信片段不单独入选（护栏）

**输入**：某段置信度 0.62，内容为观点句；无其他高置信旁证。

**期望输出**：标「转写待核」，不单独作为入选段依据；由 AI 局部重识别或上下文复核，仍存疑则不入选。

**断言**
- [ ] 低置信段未直接入选；
- [ ] 风险清单登记该段；
- [ ] 未凭低置信文本写保留理由。

## 样例 13：D1 措辞与转写不符（护栏）

**输入**：D1 金句封存写法为「封存写法甲」，转写为「转写写法乙」，两次识别一致但与封存口径不同。

**期望输出**：保留项核对标「措辞不符」，登记需求单写法与转写写法；AI 二次识别两次一致按识别取值，冲突取保守表述；不照搬转写，不擅改需求单。

**断言**
- [ ] 两种写法都记录；
- [ ] 结论为 AI 复核取值或保守表述；
- [ ] 未直接采用任一版本写死字幕。

## 样例 14：说话人映射与编号对照（护栏）

**输入**：ASR 输出 sp1、sp3；sp3 在自报姓名处说出「我叫观众甲」，其余 sp3 发言为现场观众。

**期望输出**：结构单记录 ASR 编号与推定身份；sp1=主讲人，sp3=观众（观众甲）；同编号内笑声与发言拆开标注。

**断言**
- [ ] 编号与真实姓名分离登记；
- [ ] 推定身份有上下文依据；
- [ ] 笑声未混入发言段。

## 样例 15：转写缺失与截断（护栏）

**输入**：转写末段临近结尾处截断，开头短段无文本。

**期望输出**：风险清单登记转写缺失时间段；缺口段标「转写缺失」，不推断内容、不当作无发言。

**断言**
- [ ] 缺失时间段列明；
- [ ] 未给缺口补造台词；
- [ ] 主干若被缺失覆盖则触发暂停 P1 判定。

## 样例 16：术语误写前置校准（护栏）

**输入**：转写将课程英文名识别为近似错误拼写，将俱乐部名识别错。

**期望输出**：摘要按 D3 改回正确写法，备注原转写误写；未收录专名标术语待核。

**断言**
- [ ] 摘要用正确写法；
- [ ] 原误写在备注留痕；
- [ ] 未把误写带入结构单正文。

## 样例 17：肢体笑点证据来源（护栏）

**输入**：D1 指定「学大猩猩扮丑」，转写仅有「表演了一段大猩猩」文本，动作画面无法从文字判断。

**期望输出**：证据来源标「需画面核验」；肢体动作列入待核，由 P2 抽帧或视频理解核验，不能确认则降格不作笑点依据。

**断言**
- [ ] 证据来源区分文字可证 / 需画面核验 / 需音频核验；
- [ ] 未凭文字断言动作细节；语调起伏、笑声掌声归入需音频核验；
- [ ] 待核环节指向 AI 画面或音频核验而非人工看片听片。

## 样例 18：转写不可用降级（护栏）

**输入**：低置信片段占比超三成，说话人编号全部混淆，主干段落多处缺失。

**期望输出**：暂停 P1，回 P0 补转写或缩小选段范围；不强行输出结构单。

**断言**
- [ ] 触发降级条件被识别；
- [ ] 未硬出选段方案；
- [ ] 回退节点与所需材料写明。

## 样例 19：轻口径转写无编号、无置信度（护栏）

**输入**：转写结果只有起止时间码与文本，无 speaker 字段、无 confidence 字段。

**期望输出**：身份按上下文推定，编号列留空不编造；不做自动低置信分级，通读标记语句不通、专名存疑片段；关键内容由 AI 二次识别复核。

**断言**
- [ ] 未编造 ASR 编号；
- [ ] 未引用不存在的置信度做分级；
- [ ] 关键内容仍由 AI 复核；
- [ ] 存疑片段有明确待核状态。

## 样例 20：D1 指定项因禁区/授权未能保留（护栏）

**输入**：D1 指定一处观众互动点名，A5 显示该观众仅限内部使用；该互动段落在候选范围。

**期望输出**：保留项核对表标「未能保留」，注明剔除原因（授权不足）与对成片目标的影响，列入待确认；不把该互动计入保留清单，也不删除 D1 登记痕迹。

**断言**
- [ ] 未能保留项在核对表留痕；
- [ ] 剔除原因与影响写明；
- [ ] 列入待确认项并带截止节点；
- [ ] 未把未授权互动伪装成保留段。

## 样例 21：表情肢体与语调高点不漏标（踩坑回归）

**输入**：转写文本措辞平淡，但原片同一时段存在一处夸张肢体动作、一处语调陡升的强调句、一阵观众大笑；按文本相似度初筛时这几处差点被略过。

**期望输出**：肢体动作标「需画面核验」，语调起伏与笑声掌声标「需音频核验」；这些高点归入「情绪点缀」环节并依附相邻主干段；不因转写文本平淡而漏标高光点；两类核验由 AI 抽帧/带音频理解或音频特征完成，无法佐证再降格。

**断言**
- [ ] 肢体、表情、走位归入需画面核验；
- [ ] 语调起伏、重音停顿、笑声掌声归入需音频核验；
- [ ] 未仅凭文本平淡度筛掉情绪高点；
- [ ] 核验无法佐证的高点已降格留痕，不硬保留。

## 样例 22：同案例相邻段合并（护栏）

**输入**：同一案例分前后两段相邻入选（前段交代情形、后段给出反差结果），两段合计约 80 秒，目标主片 5–7 分钟。

**期望输出**：可建议合并为一段控制时长；合并后重新登记主/副角色、净时长与身份归属；是否合并列入待确认由闸口定，不在后续节点擅自并段。

**断言**
- [ ] 同案例相邻段给出合并建议与合并后口径；
- [ ] 合并后角色、时长、身份重新登记；
- [ ] 合并决定列入待确认，未在 P2 擅自并段。

## 样例 23：多来源时间码冲突（护栏）

**输入**：同一金句锚点，转写稿记 t1，二次理解模型记 t2，两处不一致。

**期望输出**：并列两个来源与时间码，回该区间交叉复核；仍不一致则挂「待核」，不按任一来源写死时间码；复核结论记入风险清单。

**断言**
- [ ] 两来源时间码并列登记，未取其一覆盖；
- [ ] 回区间交叉复核，仍不一致挂待核；
- [ ] 未凭单一来源写死时间码或保留理由。

## 样例 24：动作峰值句点外待补帧（护栏）

**输入**：一段肢体扮丑动作，转写台词句点落在动作叙述处，但动作顶点发生在两句台词之间。

**期望输出**：备注标「动作峰值待补帧」；交 P2 在动作区间内取起势/峰值/回落多张或短片段，不只锚定台词句点抽帧。

**断言**
- [ ] 动作段带「动作峰值待补帧」备注；
- [ ] 未按台词句点推定动作顶点时间码；
- [ ] 补帧要求指向 P2 动作区间多点取证。

## 样例 25：例证脱离所属论点（护栏）

**输入**：转写稿中一个例证段分三处：前置铺垫「为说明主张 A，先交代背景」；中段两组例证对比（例证甲与例证乙的差异）；后置落点「由此回到主张 A 的结论」。草案只选中段对比短段。

**期望输出**：判定该段不自足——只剩「两组例证不同」的奇观，没有主张与落点；回补前置论点铺垫与后置落点句，或与相邻同论点段合并为「铺垫—例证—落点」完整链条；保留理由标明该段为例证及其所属主张位置；压缩时不得砍掉论点句或落点句。

**断言**
- [ ] 只含例证对比、无论点主张与落点的段被判不自足；
- [ ] 回补论点铺垫句与落点结论句，或按同论点合并归并；
- [ ] 保留理由登记例证所属主张落在前置还是后置段；
- [ ] 未在压缩时砍掉论点句或落点句；
- [ ] 未把纯例证当作可独立成立的金句。

## 样例 26：互动案例缺论点目的且前半段拖沓（护栏）

**输入**：学员互动案例——前置主讲布置「演示动作 A、引出主张 B」；中段学员甲上台，主讲反复引导排练与来回；后段学员甲讲自己的经历；落点主讲复盘回到主张 B。草案只选学员自报家门与经历段，含整段排练引导来回，未纳入目的句与落点。

**期望输出**：判不自足且前半段拖沓；回补发起目的句（演示动作 A、引出主张 B）与落点（回到主张 B）；排练指导、引导来回、无效起哄压缩或剔除；同一案例前后半场合并；压缩不砍目的句、核心冲突与落点。

**断言**
- [ ] 互动段回补发起目的句，说明请该学员上台佐证什么主张；
- [ ] 落点结论句回补或随合并归并；
- [ ] 排练引导来回、无效起哄被压缩或剔除，未当内容保留；
- [ ] 同案例前后半场合并归并；
- [ ] 压缩未砍掉目的句、核心冲突与落点句。

## 样例 27：高置信但语境不通的误识降格（护栏）

**输入**：一段围绕主张 A 的发言，二次识别两次都产出不通短语甲（conf 0.89 / 0.98），另一句产出不通短语乙；两个短语在主题与上下文里都不存在对应名词，音近错配，整句语义断裂。

**期望输出**：不因置信度高就放行；标「转写待核」，二次识别并结合上下文比对；两次仍不通或证据不足则降格——摘要与成片字幕只用上下文可佐证的保守表述，不照抄不通短语甲、乙，也不臆造正确原词；风险清单登记原误识文本、复核结论与降格处置。

**断言**
- [ ] 高 conf 但语境不通的短语未按高置信直接放行；
- [ ] 不通短语未照抄进摘要或成片字幕；
- [ ] 风险清单登记原误识文本与降格处置；
- [ ] 保留可佐证的保守表述，未凭推测写死正确原词。

## 回归判定规则

- 每条样例断言逐条通过；
- 出现臆造时间码、越界产物、跳过禁区/授权检查、强行凑时长、自造收尾观点任一情况，判不通过；
- 正向样例与护栏样例均不可省略。
