# 第五步 · 金句切片（P4）字段契约与判定规则

> 配套 `assets/prompt-p4-clips.md`（v1.3）。本文件定义切片产物字段、选题来源、时长区间、独立成立判定、主片口径沿用、切片包装与回退分层，供 Skill 实现与测评核对使用。授权、脱敏、术语、字幕与配乐口径以第一步到第四步（P0–P3）锁定结论为准。要素通俗名对照见 SKILL 总纲对照表。

## 1. 输入前置条件

| 输入 | 来源 | 缺失处理 |
|---|---|---|
| 已定稿主片 | 第四步（P3）人工确认环节确认 | 主片未定稿回 P3，不在草案/待确认片上另切切片 |
| 锁定需求单 | 第一步（P0） | D1 保留清单、D3 术语、A5-1/A5-2 授权、B4 画幅、B5 口径、A5-3 配乐、B3 期望动作、C3-模式 板位方式、C3 标题文案、C2 片尾口径 |
| 结构单与核验记录 | 第二步/第三步/第四步（P1/P2/P3） | 段时间码、角色身份、降格留痕项、口径待改段、段证据等级；沿用其结论，不回改主片结构 |
| 主片遗留确认环节项 | 第四步（P3）包装记录 | 底板构图、字幕大小、背景残留、配乐等待复核项；切片继承并登记，随主片终封一并复核 |

P4 开始前必须确认：主片状态为「已定稿」；拟选切片段在结构单中可定位、核验结论齐备；切片内主体授权逐项可对外。缺项挂「待补」并注明归属节点，不放宽授权、不代拟文案。

## 2. 前置校验与回退分支

| 情形 | 处置 |
|---|---|
| 主片仍为草案预览、待确认或包装未过闸口 | 常规回 P3 先定主片；确需先看切片方向时，仅可出标注清晰的「切片预览样片」：显式标未定稿、不标可发布终版、不进发布闸口；主片定稿后按同一时间码重跑，不直接沿用预览样片 |
| 选题段取不到时间码，或核验结论缺失 | 不进切片清单，挂待核；待结论补齐后再判 |
| 授权为 `未确认` / `仅限内部` / `明确拒绝` | 对应主体从切片剔除或挂风险；`明确拒绝` 触发停止分支，不进可发布状态 |
| 主片阶段已降格、存疑、未授权的段落 | 不进入切片；沿用 P1/P2/P3 留痕结论 |
| 发现未在 P1/P2/P3 登记的禁区内容 | 回 P0/P1 补登；切片阶段不自行删改主片结构 |

## 3. 切片产物字段定义

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 选题类型（E1） | 枚举 | 是 | 金句 / 观点 / 笑点 / 互动 / 落点；一片一个看点 |
| 源时间码区间 | 结构化 | 是 | 取自母带或已核验素材；与结构单时间码对照一致 |
| 切片时长（E2） | 数值 | 是 | 目标 60–90 秒；登记实测时长与区间偏差 |
| 独立成立结论（E3） | 枚举 | 是 | 成立 / 需回补 / 撤下；附钩子—论点—落点齐备性说明 |
| 授权核对 | 结构化 | 是 | 切片内主讲、嘉宾、观众、画面素材逐项沿用 A5-1/A5-2 |
| 段证据等级 | 枚举 | 是 | 逐段沿用 P1/P2 核验结论：文字可证 / 需画面核验 / 需音频核验；未达核验等级的段不强化为反应高点 |
| 口径沿用项 | 列表 | 是 | 脱敏（B5）、术语（D3）、字幕裁决、配乐（A5-3）的沿用结论 |
| 继承遗留项 | 列表 | 否 | 从 P3 包装记录继承的底板构图、字幕大小、背景残留、配乐等待复核项；随主片终封一并复核 |
| 标题/封面 | 结构化 | 否 | 按封存 C3-模式 执行；`标题板`/`标题板+尾片` 时填写，标题逐字取自 C3；只概括本切片实际内容，不夸大不剧透；未经核定的备选工作标题只留备注，不进板段、不冒充封存文案 |
| 配乐状态 | 结构化 | 是 | 已定 AI 生成垫乐（提示词/曲风/配器/电平）或「无配乐样片」；无配乐须显式标注，人声电平单独复核，不冒充可发布终版 |
| 切片板位 | 枚举 | 是 | 沿用封存 C3-模式：`无板` / `标题板` / `标题板+尾片`；未指定兜底 `无板`；尾片沿用 C2 口径 |
| 字幕方案 | 枚举 | 是 | 沿用主片字幕结论；降格/存疑项不上切片字幕 |
| 配乐 | 结构化 | 是 | AI 生成提示词、曲风、配器、人声形态、电平；人声优先 |
| 待复核项 | 列表 | 否 | 归属节点、说明、截止节点；含 R3 口号品牌复核 |
| 版本记录 | 列表 | 是 | 每片版本号、相对上一版变更点、回退依据；未采用候选选题在备注留痕 |

## 4. 选题规则（E1）

1. 单点优先：金句、明确观点、笑点段落、互动瞬间、收尾落点各成一片；一片只讲一个看点，不把多个独立论点压进同一片。
2. 选题只能来自 D1 保留清单与 P1 结构单已确认段落；话题旁支、闲聊铺垫、排练起哄、口径待改段不作为切片选题。
3. 互动类切片只保留双方身份已登记的互动；身份未推定、说话人编号缺失的互动段不单独成片。
4. 切片从母带/已核验素材按选题独立取材，不在主片上硬裁；不把主片结尾或中段一刀切下当切片。

### 4.1 选题类型枚举

- `金句`：可独立引用的观点句或设问—回答组合。
- `观点`：一个完整论点—论证—落点链。
- `笑点`：带动作或反应佐证的笑点段落；动作峰值已核验。
- `互动`：身份已登记的双方互动，问答或反应完整。
- `落点`：收尾结论段，单独成篇时自带背景交代。

## 5. 时长规则（E2）

| 情形 | 处置 |
|---|---|
| 单片 60–90 秒 | 进入独立成立判定 |
| 不足 60 秒 | 回补同主题论点或落点，或与同主题段落合并；不灌水拉长、不拼无关内容 |
| 超出 90 秒 | 只给拆片建议（按论点/反应切点）；不压缩到丢失完整论证；拆出的各新片重新走 E1 选题定位与 E3 独立成立判定，不按原链直接分段交付 |
| 需求单指定其他目标区间 | 以需求单为准；未定值用 60–90 秒 |

开场钩子与落点计入时长，不另加主片式长片头。

## 6. 独立成立判定（E3）

1. 三要素齐备：每片自带开场看点（钩子）、主体论点/事件、落点；观众没看过主片也能懂。
2. 指代补交代：片内人物、场合、背景用一句可懂概括交代；依赖主片上下文才明白的称呼、缩写、内部梗，在字幕或片内补足，不留悬浮指代。
3. 例证依附论点：例证/对比/奇观不脱离所属论点单独成切片；自足段回补背景或按同主题合并，不靠片头片尾硬接。
4. 不承接上下文：切片开场不接主片上文，结尾不依赖主片下文；不保留只有主片才成立的承接句。

### 6.1 判定结论枚举

- `成立`：三要素齐备、指代可懂、不依赖主片上下文，可进入包装。附注分级 `成立（带轻微承接）`：三要素齐备但开场留轻微承接词，次句自足可懂；可在简介层补背景，或后移起点并回补同主题内容，后移后须仍 ≥60 秒。
- `需回补`：缺背景交代或落点，回补同主题论点/落点后重判。
- `撤下`：回补后仍不自足，或授权/口径不通过；不进入切片清单。

## 7. 口径沿用（继承主片结论）

| 口径 | 沿用规则 |
|---|---|
| 授权（A5-1/A5-2） | 切片主体与主片同口径，按主体核对；不因单独分发重新放宽。L3 招募片：切片授权逐项继承主片 §2.3 留档，主体与素材状态逐片复核，`未确认` 不进切片；主片授权到期或撤销，对应切片同步撤下 |
| 脱敏（B5） | 内部称呼、行话、内部梗在字幕与包装层清理；原片语音不替换；无联系方式、内部数据、禁录内容 |
| 术语（D3） | 称呼、头衔、机构名、活动英文名、人名、引用人物名按写法表核对；大小写、连写、用字一致 |
| 字幕 | 沿用 P3 裁决结论；降格短语、存疑词、低置信未复核项不上切片字幕；不叠双字幕 |
| 配乐（A5-3） | AI 音频生成工具自创垫乐（文生 WAV），不走曲库检索下载；工作流自拟提示词，人声优先，BGM 不压切片人声；音轨机检与试听结论沿用 P3，切片不单独放宽响度与人声避让 |
| 声音事件 | 观众应答、掌声、笑声随 A5-1 观众授权核对；声音事件核验等级未达标的，不强化为反应高点，不据此定选题 |
| 主片遗留闸口项 | 底板构图、字幕大小、背景残留等待复核项随切片继承并逐条登记；主片终封后切片同步复核，不在 P4 单方面改构图或背景 |

## 8. 切片包装

1. 画幅默认沿用 B4；B4 多平台清单为切片渠道单独注明比例的，按注明执行；构图沿用主片安全区口径，关键动作与多人同框不裁切，不拉伸变形。
2. 板位按封存 C3-模式 执行：`无板` 不加标题板与尾片；`标题板` 仅加一行标题板，标题逐字取自封存 C3；`标题板+尾片` 另加切片尾片，组织标识与引导语沿用 C2 封存口径；未指定兜底 `无板`。板位排版规则沿用 P3，本节点不新拟品牌信息与切片标题。标题板版式对齐 P3 可读口径：标题按主标题档字号下限（1080 宽画布 ≥60px），一行超宽先拆行、不靠缩字硬塞；文字留在左右安全边距内，不贴边、不溢出、不被裁切；标题板停留以文案读完为准、不短于可读下限，需求单未定值登记待确认；底色与同片包装统一，深浅底字色对比可读。
3. 封面与标题只概括本切片实际内容；不夸大、不写「必火」类诱导表述、不剧透其他切片落点；不加报名催单与留资入口。未经 P0 封存核定的备选工作标题只记入备注，不上板段。
4. 各片登记选题类型、源时间码、时长、独立成立结论、授权核对、段证据等级、口径沿用项、继承遗留项、配乐状态与生成提示词。

## 9. 核验回写

| 核验项 | 通过标准 | 不通过处置 |
|---|---|---|
| 独立成立 | 开场看点、论点、落点齐备；指代已补交代；不依赖主片上下文 | 回补背景或撤下；悬浮段不进入切片清单 |
| 口径 | 授权逐项一致；脱敏与术语按 D3/B5；存疑降格项未上字幕；配乐人声优先 | 未授权项剔除挂风险；口径问题回 P3 复核 |
| 包装 | 构图不出框、动作同框完整；标题不夸大不剧透；无催单留资 | 调整标题/构图；越界表述撤下 |
| 完整性 | 每片可解码；时长在区间内；抽查帧非黑屏、主体字幕在位；无叠双字幕 | 缺陷片重裁重拼后再交闸口 |

## 10. 问题回退分层（不跨层处理）

| 问题类型 | 归属节点 |
|---|---|
| 选题不足、段落自足性差、论点—论证—落点不齐 | 回 P1 |
| 授权/禁区遗漏、未授权主体入镜切片 | 回 P0/P1 |
| 构图、字幕、配乐、首尾片包装问题 | 回 P3 |
| 切片内仍有内部口径、存疑词未清 | 回 P3 口径层复核 |
| 品牌口号长期可用性、发布前隐私与对外口径复核 | 留发布前闸口（R3） |
| 调色精修、复杂特效 | 留后续节点；P4 不做电影化调色 |

## 11. 第五步（P4）完成判定（人工确认环节）

切片清单与各片必须满足：
- [ ] 每片时长在 60–90 秒区间，单片一个看点，未灌水凑长、未压多论点；
- [ ] 每片开场看点、论点、落点齐备，脱离主片可懂，指代已补交代；
- [ ] 授权、脱敏、术语、字幕、配乐沿用主片结论，未放宽授权、未混入内部口径；段证据等级已逐段登记，未核验声音事件未强化为卖点；
- [ ] 标题封面不夸大、不剧透、不催单留资；备选标题未进板段；
- [ ] 主片遗留闸口项已继承登记，随主片终封一并复核；无配乐样片已显式标注；
- [ ] 切片清单与包装记录字段完整，待复核项带归属节点与截止节点；
- [ ] 每片通过完整性自检。

### 11.2 确认环节引导形态

- 切片整体确认、选题取舍与待复核项拍板沿用全局选项卡对话框形态：单选/多选按互斥或叠加选择，卡片含选项、客观默认、后果与兜底「其他（自填）」；不生成逐格手填表格；语音与画面存疑由 AI 自核，不进闸口对话框。

## 11.1 产物完整性自检（合成后、移交人工确认环节前）

- 每片整段解码检测无错误；抽查开场、落点、动作峰值与字幕帧非黑屏、主体与字幕在位；
- 画幅、分辨率、帧率、音轨参数登记；实测时长与目标区间对照一致；
- 字幕未叠双份；标题板文字清晰可读、不被安全区裁切；配乐与人声轨道可分离复核；
- 自检结果记入切片包装记录；任一项不通过，回退到对应切片项重做，不把带缺陷的切片交闸口。
