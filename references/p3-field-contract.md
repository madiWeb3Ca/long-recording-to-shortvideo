# 第四步 · 包装成片（P3）字段契约与判定规则

> 配套 `assets/prompt-p3-packaging.md`（v1.0）。本文件定义包装产物字段、构图安全区、首尾片文案规则、字幕裁决、配乐电平、对外口径清理与回退分层，供 Skill 实现与测评核对使用。文案与术语口径以锁定需求单片头文案（C1）/片尾文案（C2）/写法表（D3）/自带字幕与水印（A6）/授权（A5）为准。要素通俗名对照见 SKILL 总纲对照表。

## 1. 输入前置条件

| 输入 | 来源 | 缺失处理 |
|---|---|---|
| 已确认粗样 | 第三步（P2）人工确认环节确认 | 未确认回 P2，不进入 P3；草案试跑预览不进包装 |
| 锁定需求单 | 第一步（P0） | B1 时长、B2 观众、B3 动作、B4 画幅、B5 口径、C1 片头与 C1-模式、C2 片尾与 C2-模式、D3 术语、A5 授权、A6 自带字幕 |
| 第三步（P2）核验记录 | 第三步（P2） | 降格留痕项、口径待改段、背景残留备注；沿用其结论，不回改画面结构 |
| F0 流程档位 | 第一步（P0） | `L1 内部回顾` / `L2 对外宣传` / `L3 正式招募`；决定包装深度与可省项，底线不减免 |

P3 开始前必须齐备：C1-模式、C2-模式、D3、A6、A5-2、A5-3；默认片头须有 C1 文案，默认尾片须有 C2 文案；缺项挂「待补」并注明归属节点，不代拟文案、不默认生成垫乐。

## 2. 前置校验与回退分支

| 情形 | 处置 |
|---|---|
| 粗样仍为草案预览或待确认 | 回 P2 先定结构；不包装草案 |
| C1-模式/C2-模式/D3/A6/A5-3 缺失或未确认，或默认片头缺 C1、默认尾片缺 C2 | 挂待补，说明归属节点；不临时拟写品牌信息 |
| 授权为 `未确认` / `仅限内部` / `明确拒绝` | 对应主体或画面素材剔除或挂风险；`明确拒绝` 触发停止分支，不进可发布状态 |
| 发现未在 P1/P2 登记的禁区内容 | 回 P0/P1 补登；包装阶段不自行删改画面结构 |

## 3. 包装产物字段定义

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 构图方案 | 枚举 | 是 | 居中裁切 / 底板填充 / 适度缩放 / 原幅直出；记录主体位置、安全区与避让说明 |
| 画幅 | 枚举 | 是 | 对照 B4 封存画幅，不按当次素材写死 |
| 片头方式 | 枚举 | 是 | `默认片头` / `首句导入` / `无片头`；未指定走默认片头 |
| 片尾方式 | 枚举 | 是 | `默认尾片` / `自备尾片模板` / `无片尾`；未指定走默认尾片 |
| 片头文案 | 结构化 | 否 | 默认片头时填写：活动名 / 主标题 / 身份行，逐字取自 C1，三行全放 |
| 片尾文案 | 结构化 | 否 | 默认尾片时填写：俱乐部全称 / 口号 / 引导语 / 场地，逐字取自 C2 |
| 字幕方案 | 枚举 | 是 | 沿用原字幕 / 擦除重压；逐条登记沿用或重压清单 |
| 字幕条目 | 列表 | 是 | 断行、停留、术语写法；存疑与降格项不写入 |
| 配乐 | 结构化 | 是 | AI 生成：生成提示词、曲风、配器、人声形态（纯音乐/伴唱）、电平说明、机检结果与试听结论；人声优先 |
| 口径清理记录 | 列表 | 否 | 清理的内部称呼 / 行话 / 梗及对应段落；原片语音不回删 |
| 待复核项 | 列表 | 否 | 归属节点、说明、截止节点；含 R3 口号品牌复核 |
| 版本记录 | 列表 | 是 | 每版版本号、相对上一版变更点、回退依据；未采用的候选方案在备注留痕 |

### 3.1 L1 轻包装裁剪（内部回顾档）

| 项 | L1 处置 | L2/L3 处置 |
|---|---|---|
| 首尾板 | 可无品牌首尾板；如需身份标识，仅一行极简主讲人/活动条，不排品牌全称、口号、引导语、场地四行 | 按 C1/C2 封存方式出默认板/自备模板/首句导入 |
| 品牌 logo | 不放置；授权与用法未核实时位留空 | 按 §5.3 规范放置与登记 |
| 配乐 | 默认无 BGM；如需垫乐记为内部试用，不做可商用核实，不登记正式生成曲 | 按 §7 AI 自创口径生成，登记提示词/曲风/电平 |
| 口径清理 | 内部观众口径豁免，内部称呼/行话可保留；他人隐私与禁录内容仍不上 | 按 §8 对外口径逐条清理 |
| 包装记录 | 简记构图、字幕、配乐有无即可；版本台账从简 | 完整包装记录与版本留痕 |

L1 仍不可减免：主体构图不出框、关键动作与同框完整；字幕达可读下限、无叠双字幕；隐私脱敏；不催单、不留资、不放联系方式；成片可解码、无黑屏破损。

### 3.2 L3 正式招募加严裁剪

L3 在 L2 全套包装之上，以下各项逐项落位并留档；未闭合项不上片：

| 项 | L3 处置 |
|---|---|
| 首尾板 | 组织全称、口号、logo、头衔按官方品牌规范核定后上片；规范未覆盖的写法标「待品牌复核」，不沿用旧海报稿或临时口述 |
| 字幕与口径 | D3 术语台账逐项核对；内部称呼、行话、内部梗在字幕与包装层全量清理；片内不出现未公开内部数据 |
| 配乐 | AI 生成曲可商用/公开传播授权在发布前闭合登记；未核可商用状态的曲不作为 L3 上线配乐 |
| 授权 | 人物与画面素材逐项留档沿用 P0 §2.3；`未确认` 主体与素材剔除出片 |
| 复核台账 | 发布前复核台账（复核项/状态/责任人/截止节点）随包装记录归档；四项全闭才可标可发布 |

### 3.3 档位升档重做范围

L1 轻包装产物后续升 L2/L3 时，按下表区分复用与重做，不在旧轻单上直接补品牌项：

| 产物 / 口径 | 升档处置 | 重做要求 |
|---|---|---|
| P2 粗样结构 | 可复用 | 选段结构与衔接不回退；授权存疑段回 P1 剔除或补核 |
| 字幕 | 部分复用 | 内部称呼/行话按对外口径重新清理；术语按 D3 重核；存疑降格项不回写死 |
| 片头板 | 重做 | 补核定后的活动名/身份行；L3 加品牌规范项与 logo 版本登记 |
| 片尾板 | 重做 | 补 C2 组织全称/口号/引导语/场地；L3 按品牌规范排版 |
| 配乐 | 重做 | L1 内部试用垫乐不作为可商用曲；L2/L3 重新生成并留授权口径 |
| 包装记录 | 补登 | 补授权、品牌、配乐台账与待复核项，标注升档版本 |

## 4. 构图规则（B4）

1. 按目标画幅重构图；原片 16:9，不拉伸变形，不直接压扁成 9:16。
2. 主体居中偏上；预留顶部标题区与底部字幕安全区；各段主体位置一致，不忽大忽小。
3. 下沿桌面杂物、道具品牌露出（如现场购物袋）避让，不贴边、不压主体；前景道具按 A6 登记为现场露出而非水印，只避让不模糊处理（另有要求除外）。
4. 主讲关键手势、动作、表情不被裁切；多人互动保留同框，不把副角色裁出画面。
5. 背景残留无关画面（如收尾段仍停留上一章节画页）列入构图核验回写；属现场画面的，不在 P3 凭空替换背景，交回退清单记录。

### 4.1 构图方式枚举

- `居中裁切`：主体位于横屏中段，上下/左右裁去冗余；适用于单人主讲、主体居中的段落。
- `底板填充`：横屏缩放后上下留模糊或纯色底板补满竖屏；适用于裁切会丢失主体动作的段落。前景尽量放大到可读满宽，底板仅作补边，上下占比尽量均衡、前景垂直居中；前景高度与位置记入包装记录。
- `适度缩放`：整体缩放并定位主体，配合安全区微调；适用于多人同框与宽幅 PPT 段落。
- `原幅直出`：原片比例与目标画幅一致（如 16:9 横屏出 16:9）时采用；不裁切主体、不补底板、不拉伸变形，主体居中保留原幅，仅在安全边距内微调位置；适用于横屏主片与多人同框段落。

## 5. 首尾片文案规则

### 5.1 片头（C1）逐字使用

> 片头方式：`默认片头` 按下表逐字排版；`首句导入` 不生成独立片头板，主片开头约 5 秒叠加一行 C1 导入句，不留片头静音段；`无片头` 不生成片头板，主片直接起，不留片头静音段。

| 行位 | 文案来源 | 规则 |
|---|---|---|
| 活动名 | `<C1 活动名>`，取自封存需求单 | 英文连写与大小写按 D3 核对 |
| 主标题 | `<C1 主标题>`，取自封存需求单 | 不自行改写、不另拟副标题 |
| 身份行 | `<C1 身份行>`，取自封存需求单 | 三行头衔全放；旧海报稿头衔、英文名、作废表述不上片 |

> 本期实例文案见对应需求单 C1；规则层不固化具体品牌名、活动名与人头衔。

#### 5.1-bis 身份行未核定的泛称降级

- 主讲/嘉宾姓名、头衔、机构名未经用户核定或二次识别仍存疑时，片头身份行不上存疑真名、头衔、机构名；改用可懂泛称（如「主讲人」「嘉宾」「圆桌嘉宾」），不代拟、不按转写推测补全。
- 泛称条目在包装记录中标「身份待补」，回 P0 补采或 P3 复核后再上核定身份；L2/L3 对外片身份行同时挂「发布前待复核」。
- 仅内部回顾（L1）可沿用内部称呼；对外片未核定前不把内部称呼、转写误识名推上片头。

### 5.2 片尾（C2）逐字使用

> 片尾方式：`默认尾片` 按下表逐字排版；`自备尾片模板` 套用用户提供的俱乐部模板，沿用其版式与文案结构，只做竖屏适配，不擅自改写模板文案；`无片尾` 不生成片尾板，主片直接止。

| 行位 | 文案来源 | 规则 |
|---|---|---|
| 俱乐部全称 | `<C2 俱乐部全称>`，取自封存需求单 | 字母大小写与连写按 D3 核对 |
| 口号 | `<C2 口号>`，取自封存需求单 | R3：若未列入固定 slogan，本期确认沿用；标「发布前待品牌复核」，不擅自替换 |
| 引导语 | `<C2 引导语>`，取自封存需求单 | 引导浏览内容，不导向报名 |
| 场地 | `<C2 场地>`，取自封存需求单 | 逐字登记 |

> 本期实例文案见对应需求单 C2；规则层不固化本期组织名、口号与地址。

- 片尾不做报名催单、不放留资入口、不放可识别联系方式（B3）。
- 封面图为剪映默认自带封面，仅参考，不进成片（A1）。

### 5.3 片尾品牌 logo（选填）

| 项 | 规则 |
|---|---|
| 是否必放 | 选填。有规范授权的 logo 文件且品牌用法允许时放置；缺素材或授权未核实时该位留空，不补造 |
| 素材来源 | 使用品牌资产库的正式文件（PNG/SVG）；不从视频帧、海报照片里截取翻拍 |
| 版本适配 | 深色底用反白/白色版，浅色底用全彩版；不自行改色、不改比例、不拉伸、不重排、不加阴影描边 |
| 排版 | 多枚 logo 横向并排、基线对齐、间距一致；尺寸与片尾文字层级协调，不压文案 |
| 登记 | 每枚 logo 的名称、文件来源、版本（反白/全彩）、授权状态写入包装记录 |
| 回退 | 素材不清晰、通道异常或授权存疑 → 该位留空，仅保留 C2 文字片尾 |

### 5.4 板上文字可读字号（手机竖屏）

| 层级 | 字号下限（1080 宽画布） | 说明 |
|---|---|---|
| 主标题 / 品牌全称 | ≥60px | 片头主标题、片尾俱乐部全称 |
| 口号 / 身份行 | ≥40px | 片尾口号、主讲身份 |
| 辅助信息 | ≥30px | 活动名、引导语、场地地址 |

- 左右安全边距 ≥90px；一行超宽先拆行，不靠缩字硬塞。
- 深色底用白/黄字、浅色底用深色字，保证对比；沿用原烧录字幕按 A6 裁决，重压字幕同按本对比度要求。

### 5.4-bis 重压字幕正文字号（手机竖屏）

| 层级 | 字号下限（1080 宽画布） | 说明 |
|---|---|---|
| 重压字幕正文 | ≥56px | 底部居中、白字黑边（Outline ≥3）；面向含近视/老年受众时取下限上沿（本期实例 58px）；避让下沿桌面道具，不压杯口/杂物 |

- 一条字幕不超过两行；超宽先断行，不靠缩字硬塞；字号放大后仍须在左右安全边距内不溢出。

### 5.4-ter 板上文字与字幕字号（横屏 960 宽画布）

| 层级 | 字号下限（960 宽横屏画布） | 说明 |
|---|---|---|
| 主标题 / 品牌全称 | ≥48px | 片头主标题、片尾组织全称 |
| 口号 / 身份行 | ≥32px | 片尾口号、主讲身份 |
| 辅助信息 | ≥24px | 活动名、引导语、场地地址 |
| 重压字幕正文 | ≥44px | 底部居中、白字黑边；避让下沿桌面道具 |

- 左右安全边距 ≥70px；一行超宽先拆行/断行，不靠缩字硬塞。
- 横屏画布宽与竖屏基准宽不同时，按两画布宽度比例折算字号下限，折算后不取低于上表横屏档位的值；对比度、断行、避让规则同竖屏。

### 5.5 首尾板版式与音轨一致性

> 本节规则仅对生成板段的方式（默认片头/默认尾片/自备尾片模板）生效；`无片头`/`无片尾` 时无对应板段，不套用时长与底色规则。

| 项 | 规则 |
|---|---|
| 底色统一 | 首尾板底色同片一致；有品牌规范色用品牌色，缺规范时用同一兜底深色，不一头一尾两套底色 |
| 停留时长 | 片头 ≥3s、片尾 ≥4s，以文案可读为准；需求单未定值时用默认并登记待确认 |
| 板段音轨 | 板段配与主片同参数的静音音轨（采样率、声道一致），拼接处无音轨断裂 |

## 6. 字幕裁决表（A6 / D3 / R9）

### 6.1 沿用 vs 擦除重压

| 方案 | 触发条件 | 处置 |
|---|---|---|
| 沿用原字幕 | 拟用字幕与原片烧录字幕在位置、样式、断行上基本一致 | 保留原字幕，不擦除、不重压，避免叠出双字幕 |
| 擦除重压 | 需关键字放大、换字体/颜色/位置、重新断行或重排 | 先评估擦除原字幕与残留风险，再重压；擦除方案与残留风险记入记录 |

- 裁决以逐段比对为准；同一片内可分段采用不同方案，但须在记录中逐条写明。

### 6.2 断行与术语

1. 按词组断行，每条不超过两行，不把一个词切断；停留与语句节奏匹配，不压掉反应停顿。
2. 术语严格按需求单 D3 写法表逐条核对：称呼、头衔、机构名、活动英文名、人名、引用人物名；大小写、连写、用字一致。常见误写与旧版弃用表述以 D3 弃用列为准，纠正或不上片。
3. 字幕只呈现可佐证内容；轻口径无说话人编号，不补编号、不臆测身份。

### 6.3 存疑与降格处理（R9 / P1 留痕项）

| 情形 | 字幕处置 |
|---|---|
| 金句②冲突词（两次识别一致但与封存写法冲突） | 取保守表述：省略存疑词，或不写成字幕金句 |
| 二次识别仍语义不通的降格短语 | 不上字幕，只保留可佐证的保守表述；原误识与处置在记录留痕 |
| 存疑动词 / 低置信未复核项 | 不写成字幕；挂待核，等复核结论 |
| 无法核验的情绪高点、声音事件 | 不写成字幕判断 |

## 7. 配乐规则（A5-3）

1. 垫乐由 AI 音频生成工具按片情自创（文生 WAV），不从既有曲库检索或下载曲目；工作流按片情自拟生成提示词（曲风、配器、节奏、情绪、无人声），基础曲风与配器自主判定，气质候选与试听拍板按 §7.1 处置；登记生成提示词、曲风、配器、人声形态、电平与生成版本。
2. 人声优先：主讲人声清晰可懂，配乐电平低于人声；有人声段落压低 BGM，无人声间隙可适度抬起，不盖过对话与笑声反应。
3. 不用带歌词的人声曲压主讲；生成风格与讲座主题匹配，轻松不抢戏；不堆砌夸张转场音效。
4. 曲风与人声形态由工作流按片情判定，默认纯音乐、轻快/温和氛围；伴唱类仍受第 3 条约束，带歌词人声不压主讲。
5. 生成能力边界：单次生成 ≤120 秒；长片垫乐分段生成后本地合流/循环铺底，接缝做淡出淡入；生成失败、风格不符或工具不可用时，以「无配乐样片」显式标注，不强行配乐、不回退曲库下载。
6. 授权：AI 生成曲的可商用/公开传播授权类型不在本环境前置核实；L1 记内部试用；L2 留发布前版权与授权复核；**L3 在发布前必须闭合授权状态并登记入复核台账，未核可商用状态的生成曲不上招募片**。

### 7.1 生成音轨质检（AI 自创垫乐）

生成曲合入成片前，先过机检硬指标，再做人耳试听；机检不达标就地重生成，不带着缺陷往下合成。

**机检硬指标（纯音乐垫乐通用，本地 ffmpeg 自测）**

| # | 检查项 | 判据 | 不通过处置 |
|---|---|---|---|
| 1 | 容器真实性 | 实测音频编码格式，只认探测结果、不认文件后缀；假格式或播放器不出声判失败 | 重生成；交付前自重定向下载一次，验证可解码出声 |
| 2 | 时长与铺底对齐 | 垫乐长度匹配成片或铺底区间；分段合流/循环接缝不断裂 | 裁剪补段或重新生成；接缝补淡出淡入 |
| 3 | 响度与削波 | 测 mean/max volume；生成曲普遍偏轻，不达标做 loudnorm/音量校正后复测；max 不得削波 | 校正后复测仍不达标则重生成 |
| 4 | 静音与断裂 | 标出异常长静音、器乐突断；循环铺底无突兀接缝 | 断裂段重生成；接缝做淡化处理 |

**人耳主观项（不可由模型自评通过）**

5. 试听首、中、尾三点：气质是否贴合主题；有无突然变调、器乐突断、半句含糊、莫名念白或合唱。
6. 主观项由工作流给 2–3 个候选并附一句差异说明（编曲、配器、气质）；不写「已确认好听」。L2/L3 对外片由用户试听拍板；L1 内部片可工作流自定，但须留试听结论记录。

**演唱/MV 专属（默认纯音乐垫乐不启用）**：词完整性逐句 ASR 比对、逐字时间戳表、拍点表，仅在派生带演唱曲目或 MV 时启用；本地未装 faster-whisper / librosa 等语音与节拍栈时标待验证，不凭估算时间落字幕与切点。

**留档**：生成曲 URL、生成时间、完整提示词（编曲、配器、唱法、时长参数）；机检实测值日志；授权口径沿用 §7 第 6 条，发布前复核。

红线：曲不过就地重出，不带着「先用着」往下做；画面、字幕做完再换曲属全片返工。

## 8. 对外口径清理（B5）

1. 面向外部陌生人：内部称呼、例会行话、内部梗在字幕与包装文案层清理；原片语音保留，不替换原话，对外化处理落在字幕/解说层。
2. 口径待改段：粗样按原片保留，包装阶段只做字幕对外化，不回删画面段落；清理记录对应到段落。
3. 成片不出现可识别联系方式、内部数据、禁录内容。

## 9. 核验回写

| 核验项 | 通过标准 | 不通过处置 |
|---|---|---|
| 构图 | 主体不出框、关键动作手势完整、多人同框保留；下沿杂物与道具品牌已避让；安全区无遮挡 | 回退调整构图方案；动作被裁的段落不进入成片 |
| 字幕 | 术语写法正确、断行合规、停留自然；逐条登记沿用/重压；存疑短语与降格项未进字幕；无叠双字幕 | 纠正术语与断行；存疑项撤下字幕挂待核 |
| 声画 | 人声清晰，配乐不压人声；片头/片尾按封存方式执行，默认片与 C1/C2 逐字一致 | 降 BGM 电平；文案回退逐字核对 |
| 口径 | 无内部称呼/行话/梗混入字幕；无催单、留资、联系方式；无未授权素材 | 清理口径；未授权项剔除挂风险 |

## 10. 问题回退分层（不跨层处理）

| 问题类型 | 归属节点 |
|---|---|
| 选段取舍、段落顺序、时长、连贯与节奏 | 回 P1/P2 |
| 授权/禁区遗漏、未授权主体入镜 | 回 P0/P1 |
| 口号品牌长期可用性、发布前隐私与口径复核 | 留发布前闸口（R3） |
| 独立 60–90 秒切片派生 | 主片定稿后留 P4 |
| 调色精修、复杂特效 | 留后续节点；P3 不做电影化调色 |

## 11. 第四步（P3）完成判定（人工确认环节）

包装记录与成片必须满足：
- [ ] 成片为目标画幅，主体在安全区内，关键动作与多人同框完整；
- [ ] 片头/片尾按封存方式执行；默认首尾片文案与 C1/C2 逐字一致，无催单、无留资、无联系方式；
- [ ] 字幕术语正确、断行合规，存疑/降格短语未上字幕，无叠双字幕；
- [ ] 配乐人声优先，BGM 不压人声；
- [ ] 无内部口径混入，未授权素材未进片；待复核项带归属节点与截止节点；
- [ ] 产物通过完整性自检。

**L1 完成判定（从简）**：画幅与主体完整、字幕可读无叠双份、隐私脱敏、无催单留资联系方式、成片可解码无黑屏，即过闸；品牌首尾板、logo、正式配乐与对外口径条目按 §3.1 免核。
**L2 完成判定**：逐项满足上表全部条目；品牌规范与配乐可商用状态可留发布前复核，但须在记录中挂复核项与截止节点，不默认已确认。
**L3 完成判定**：在 L2 基础上，授权逐项留档、品牌规范核定、配乐可商用授权闭合、发布前复核台账四项全闭；任一项未闭合，成片只标「待发布前复核」，不进入可发布状态。

### 11.2 确认环节引导形态

- 成片整体确认、包装方式取舍与待复核项拍板沿用全局选项卡对话框形态：单选/多选按互斥或叠加选择，卡片含选项、客观默认、后果与兜底「其他（自填）」；不生成逐格手填表格；语音与画面存疑由 AI 自核，不进闸口对话框。

## 11.1 产物完整性自检（合成后、移交人工确认环节前）

- 成片整段解码检测无错误；抽查片头、片尾、各衔接段与字幕峰值帧非黑屏、主体与字幕正常；
- 成片画幅、分辨率、帧率、音轨参数登记；时长与粗样净时长对照一致，差值在段间余量范围内；
- 字幕未叠双份；首尾片文字清晰可读、不被安全区裁切；配乐与人声轨道可分离复核；
- 自检结果记入包装记录；任一项不通过，回退到对应包装项重做，不把带缺陷的包装片交闸口。
