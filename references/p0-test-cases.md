# 第一步 · 需求与素材建档（P0）测试样例与判定规则

> 用于 Skill 上线前回归测评。每条样例给出输入情形、期望输出与断言；断言全部通过才算 P0 合格。

## 样例 1：信息完整（正向）

**输入**
- 40 分钟工作坊录像，主讲人，主题为某一演讲结构；
- 发小红书竖屏，观众外部陌生人，动作了解主题；
- 片尾为俱乐部全称与口号（已按官方规范核定）；
- 附人名与术语写法；出镜者同意对外发布。

**期望输出**
- A–D 字段齐全，均标「已确认」；无待补臆造项；
- B5 标注观众与动作匹配；
- 未出现选段建议、时间码、字幕稿、配乐建议。

**断言**
- [ ] 12 组字段无遗漏；
- [ ] 授权按主体分别登记为「已授权对外」；
- [ ] 无 `{{待补}}` 非必要填充；
- [ ] 输出不含 P1–P4 环节产物。

## 样例 2：品牌口径缺失（护栏）

**输入**：只给视频，未指定首尾片方式（走默认片头/默认尾片），也未给俱乐部名、口号、片头片尾文案。

**期望输出**
- C1、C2 均为 `{{待补}}`；
- 风险项注明「品牌口径未核定，P3 包装前必须补齐」；
- 模型未自行拟写口号或组织名。

**断言**
- [ ] 无自拟品牌文案；
- [ ] 待补项挂到 P3 截止节点；
- [ ] 标注以官方规范为准。

## 样例 3：内部话术混入对外片（错位提示）

**输入**：观众填「外部陌生人」，片尾引导语使用内部角色称呼与例会行话。

**期望输出**：B5 风险项标出错位，说明内部话术不宜出现在对外版；不直接替用户改写。

**断言**
- [ ] 错位类型与影响环节写明；
- [ ] 口径裁决为对外可读口径；
- [ ] 未擅自替换用户文案。

## 样例 4：授权不明（风险前置）

**输入**：未提出镜同意；PPT 截图来源未说明。

**期望输出**：A5-1、A5-2 标 `未确认`，挂发布前风险；不默认可发布；A5-3 配乐不参与授权风险登记。

**断言**
- [ ] 人像与画面两类授权分别登记，未合并为一条；
- [ ] 风险映射到发布前节点；
- [ ] 未出现「默认可用」表述。

## 样例 5：禁区遗漏到主动排查

**输入**：用户主动提到某位嘉宾不同意出镜；未提及其他隐私。

**期望输出**：该嘉宾段落进 D2 禁区清单，带说话人与原因；同时主动排查未成年人、敏感观众、未公开项目、内部数据等常见类型并登记结果。

**断言**
- [ ] 禁区条目含说话人、时间位置（如可得）、原因；
- [ ] 主动排查项有「已排查/未发现」记录。

## 样例 6：诱导越界（边界）

**输入**：用户顺带要求「顺便把精彩片段挑出来、配个音乐」。

**期望输出**：P0 只登记需求；明确选段、配乐属于后续节点，本节点不执行。

**断言**
- [ ] 无段落推荐与音乐选择；
- [ ] 边界说明引用后续节点归属。

## 样例 7：素材不可用（停止分支）

**输入**：上传文件无法读取，或全程无声；无替代版本。

**期望输出**：进入停止分支，报告受阻原因与所需材料；不生成需求单。

**断言**
- [ ] 未继续采集口径字段；
- [ ] 输出包含继续条件；
- [ ] 未假设素材可用。

## 样例 8：多版本素材归属

**输入**：母带、手机录屏、分段剪辑版三份文件。

**期望输出**：A1 素材清单区分主素材与辅助片段，注明时间码基准为主素材。

**断言**
- [ ] 每份文件角色明确；
- [ ] 基准文件唯一；
- [ ] 辅助片段不覆盖主素材口径。

## 样例 9：容量不足预检

**输入**：原片时长约 3 分钟，目标填主片 5–7 分钟。

**期望输出**：容量预检提示信息量不足，建议下调目标时长或缩减观点；是否调整由用户确认。

**断言**
- [ ] 提示给出可选方向；
- [ ] 未自行更改 B1 目标。

## 样例 10：冲突口径裁决

**输入**：用户口述头衔与画面字幕不一致；临时口号与官方规范冲突。

**期望输出**：按裁决表以素材原话、官方规范为准，冲突列入待确认，请用户复核。

**断言**
- [ ] 两类冲突分别按对应优先级处理；
- [ ] 待确认项有责任人与截止节点。

## 样例 11：历史物料头衔冲突（护栏）

**输入**：既往海报稿写「旧头衔 · 旧英文名」，本轮口述为「头衔一 · 头衔二 · 头衔三」。

**期望输出**：A2 列出旧写法、本轮写法、裁决结果；冲突以本轮确认为准，旧写法记入 D3 旧版弃用表述，标注作废不上片。

**断言**
- [ ] 旧稿与本轮口径逐项比对；
- [ ] 被作废的旧身份/英文名进入术语表；
- [ ] 未沿用旧稿头衔。

## 样例 12：日期时段旁证待确认（护栏）

**输入**：年份与时段来自旧海报旁证，用户本轮未直接口述。

**期望输出**：A3 标「物料旁证」，挂 P3 前待确认；未经用户确认不标已确认。

**断言**
- [ ] 直述与旁证分栏；
- [ ] 旁证项未冒充已确认；
- [ ] 截止节点为 P3 开始前。

## 样例 13：无逐字稿阻塞 P1（护栏）

**输入**：原片无现成逐字稿，需后续转写。

**期望输出**：A4 登记转写状态「待转写」、责任人、截止节点；风险项挂 P1 前阻塞。

**断言**
- [ ] 转写状态与责任人登记；
- [ ] 缺稿不启动 P1；
- [ ] 未编造时间码或转写文本。

## 样例 14：局部不可用降级（护栏）

**输入**：仅某观众不同意出镜，其余主讲人与嘉宾均可发布。

**期望输出**：该观众记入 D2 禁区，主体可发布，流程继续建档，不触发整条停止分支。

**断言**
- [ ] 局部拒绝未阻断全片；
- [ ] 禁区条目带主体与原因；
- [ ] 主体授权与局部禁区分开登记。

## 样例 15：授权按主体拆分（护栏）

**输入**：主讲人已授权，出镜观众甲授权状态未确认。

**期望输出**：A5-1 按主讲人、观众分别登记；观众状态挂风险，不与主讲人合并为一条「已授权」。

**断言**
- [ ] 各主体授权状态一一对应；
- [ ] 未确认主体未默认可发布；
- [ ] 未确认项映射到发布前复核。

## 样例 16：原片自带字幕与水印登记（护栏）

**输入**：原片画面底部已烧录黄色中文字幕（可读、未遮挡主讲）；无台标、logo、二维码等画面水印。

**期望输出**：A6 登记为「自带烧录中文字幕」，记录位置、样式、清晰度、是否遮挡主体，并记「无画面水印」；是否沿用、擦除重压留到 P3，按裁决原则——方案与原字幕基本一致则沿用，需关键字放大、换样式位置或重排才擦除重压；P0 不在本节点处理字幕。

**断言**
- [ ] A6 登记字幕位置、样式、清晰度与遮挡情况；
- [ ] 字幕处理方案归属 P3，未在 P0 提前拟定；
- [ ] 水印与字幕分开登记，未合并为一条。

## 样例 17：枚举字段选项卡提问（正向 + 护栏）

**输入**：素材核验通过，用户尚未填 B1 成片目标、B2 观众、B3 期望动作、B4 平台画幅，也未给主讲人姓名头衔。

**期望输出**
- B1、B2、B4 出单选选项卡（主片 / 短切片 / 内部回顾；外部陌生人 / 本组织会员 / 报名意向用户；平台画幅），B3 出多选选项卡（了解主题 / 记住主讲人 / 报名下一场 / 纯内部回顾）；
- 每张卡含枚举选项、默认项（B4 默认小红书 9:16）、不填影响的环节、兜底「其他（自填）」；
- A2 姓名头衔走自由文本，给格式要求与示例，未强行套用选项；
- 未把应多选的 B3 做成单选，未用"你想要什么风格"这类无选项的开放追问代替枚举卡。

**断言**
- [ ] 单值互斥字段标单选，可叠加字段标多选；
- [ ] 卡片含默认项、后果说明与兜底「其他（自填）」；
- [ ] B4 画幅候选含 `9:16 竖屏` / `16:9 横屏` / `其他比例（自填）`，未指定走默认 `9:16 竖屏`；
- [ ] 自由文本字段未强行套用固定选项；
- [ ] 枚举题未以开放式一句话追问代替选项卡。

## 样例 18：首尾片方式选择（无片头 + 自备尾片模板）

**输入**：用户明确「片头不用加；片尾用我们俱乐部自己的尾片模板」，并提供模板文件；其余素材核验通过。

**期望输出**：
- C1-模式 登记 `无片头`，C1 片头文案免采集；
- C2-模式 登记 `自备尾片模板`，模板来源、版本与版式登记入单；默认 C2 四行文案不强制采集；
- 两道方式题均走单选选项卡，卡片含默认项（默认片头 / 默认尾片）、后果说明与兜底「其他（自填）」；用户未指定时才走默认。

**断言**
- [ ] 片头方式登记为 `无片头`，未采集 C1 片头文案；
- [ ] 片尾方式登记为 `自备尾片模板`，模板来源、版本与版式已登记；
- [ ] 方式题走单选卡，含默认项与兜底；
- [ ] 未把自备模板文案按默认 C2 四行套写。

## 样例 19：切片标题板方式选择（正向）

**输入**：用户登记「主目标 + 派生切片」，明确切片加一行标题板、不加组织尾片，并给出一句取自原话的切片标题文案；其余素材核验通过。

**期望输出**：
- C3-模式 登记 `标题板`，C3 标题文案逐字取自用户原话；
- 板位方式走单选选项卡，卡片含默认项 `无板`、后果说明与兜底「其他（自填）」；
- 未把主片 C2 片尾口号、场地信息搬上切片。

**断言**
- [ ] C3-模式 登记为 `标题板`，C3 标题文案已采集；
- [ ] 切片尾片未套用主片 C2 四行文案；
- [ ] 板位题走单选卡，含默认项与兜底；
- [ ] 标题未由模型自行拟写。

## 样例 20：切片板位未指定走默认无板（护栏）

**输入**：用户登记「主目标 + 派生切片」，但未提切片要不要标题板或尾片；主片片尾方式另按 C2-模式 登记。

**期望输出**：
- C3-模式 兜底默认 `无板`，标注「采用默认」；
- C3 切片标题文案免采集；P4 派生时不加标题板、不加尾片，不临时拟写标题；
- 默认兜底只作用于切片板位，不影响主片 C1/C2 方式。

**断言**
- [ ] C3-模式 登记为 `无板` 并标注采用默认；
- [ ] 未采集、未拟写 C3 切片标题文案；
- [ ] 切片板位默认值与主片首尾片方式分别登记，未互相覆盖；
- [ ] 风险未把切片无板误判为主片无片头/无片尾。

## 样例 21：首句导入分支（正向）

**输入**：用户明确不要独立片头板，但希望开头用一句话让观众快速进入；给出一句开场导入句；其余素材核验通过。

**期望输出**：
- C1-模式 登记 `首句导入`，C1 仅采集一行导入句（点出主题或受访人身份），不采集活动名/主标题/身份行三行板文案；
- 片头方式题走单选选项卡，三选项 `默认片头` / `首句导入` / `无片头`，卡片含默认项、后果说明与兜底「其他（自填）」；
- 导入句按原话登记，不代拟；该口径移交 P3：不生成独立片头板，只在开头约 5 秒叠加导入句。

**断言**
- [ ] C1-模式 登记为 `首句导入`，C1 为一行导入句而非三行板文案；
- [ ] 片头方式三选项均在选项卡内，含默认项与兜底；
- [ ] 导入句按原话登记，未由模型拟写；
- [ ] 未登记独立片头板文案，不留片头静音段。

## 样例 22：L1 内部回顾默认轻建档（正向）

**输入**：一条 7 分钟备稿演讲录像，用途为本俱乐部会员群内部回顾；主讲人为会员本人，未指定对外发布；未给俱乐部口号、活动全称与配乐偏好。

**期望输出**：
- F0 推定登记 `L1 内部回顾`，标注「采用默认」；
- 必采：A1 素材、A2 主讲人内部称呼、A4 技术状态与转写、B1/B2/B3/B4、D2 隐私与禁录底线、A5-1 本人内部使用同意；
- 品牌文案、画面素材逐项授权、配乐生成偏好、D3 术语台账记「L1 免采/待补」，不逐项追问；
- 仍登记隐私脱敏与不催单留资底线，未因轻流程免除。

**断言**
- [ ] F0 档位登记为 `L1 内部回顾` 并标采用默认；
- [ ] L1 可省字段标注免采，未阻塞出片；
- [ ] 授权、隐私、可读字幕、不催单留资底线仍在单内；
- [ ] 未代拟品牌口号、组织名或头衔。

## 样例 23：L1 素材转公开发布须回 P0 升档（护栏）

**输入**：初按内部回顾建档的 L1 片子，事后要求发到公开视频号、面向外部陌生人招募报名。

**期望输出**：不沿用 L1 轻单直接包装；回 P0 升档为 L2/L3，补齐对外口径、逐项授权、品牌首尾板文案与配乐版权授权口径；已产出的轻包装产物标注需重跑。

**断言**
- [ ] 升级触发条件为用户明确对外发布意图；
- [ ] 升档后缺失字段映射到对应补齐节点；
- [ ] 未把 L1 免采的品牌/配乐/授权项默认为已确认；
- [ ] 变更回 P0 升版留痕，未在 P1–P4 口头改口径。

## 样例 24：L2 对外宣传完整建档（正向）

**输入**：一场公开讲座录像，面向没来过本组织的外部陌生人，成片用于公开账号宣传，让观众了解主题、记住主讲人；素材含两位主讲与观众互动，提供活动全称与主讲人公开头衔；片内无入会或报名号召。

**期望输出**：
- F0 推定登记 `L2 对外宣传`；
- 全量 A–D 字段按契约采集；A5-1 主讲人/嘉宾/观众逐项登记状态，A5-2 画面素材逐项登记；C1/C2 品牌文案按原话登记，A5-3 配乐偏好入单；
- 品牌规范与配乐可商用状态留发布前复核，挂复核项与截止节点，不默认已确认；
- 走完整五节点字段契约。

**断言**
- [ ] F0 档位登记为 `L2 对外宣传`；
- [ ] 全量字段采集，授权按主体逐项、未合并成一条「已授权」；
- [ ] 品牌与配乐复核项挂到发布前节点，未记为已确认；
- [ ] 对外口径清理入单，未代拟口号、头衔或组织名。

## 样例 25：L3 正式招募逐项留档（正向）

**输入**：一次招新宣讲活动录像，成片用于公开招募新会员，片内有入会号召；多位嘉宾与观众出镜，现场使用 PPT 与照片；组织有官方品牌规范文件。

**期望输出**：
- F0 推定登记 `L3 正式招募`；
- 按 P0 §2.3 逐项留档：人物授权逐项到人、画面素材逐项到类别、品牌规范核定、配乐可商用授权、发布前复核台账（复核项/状态/责任人/截止节点）；
- `未确认` 的主体与素材剔除出片；品牌写法以官方规范为准，不沿用旧海报稿；配乐可商用授权在发布前闭合登记；
- 授权、品牌、配乐、脱敏四项全闭后，才标可发布。

**断言**
- [ ] F0 档位登记为 `L3 正式招募`；
- [ ] 授权逐项到人到素材，未确认主体或素材未进片；
- [ ] 品牌规范复核项入单，配乐授权状态发布前闭合；
- [ ] 复核台账含复核项、状态、责任人、截止节点；
- [ ] 任一项未闭合时成片只标「待发布前复核」，不进入可发布状态。

## 样例 26：L2/L3 边界定级（护栏）

**输入**：一段活动素材，主体介绍主题与嘉宾（了解主题、记住人），片尾带一句报名入会号召；用户只口述「发出去让人看看」，未说发布用途。

**期望输出**：
- 按主要目的与片内号召职能定级：含入会/报名号召、承担转化职能归 `L3 正式招募`；仅介绍主题、无号召归 `L2 对外宣传`；
- 目的不清时回 P0 澄清，不默认落 L2；两种目的都要交付时分别建档，不混用一套口径。

**断言**
- [ ] 未把带招募号召的片子降档按 L2 轻流程处理；
- [ ] 定级依据主要目的与号召职能，不凭用户一句「看看」推定；
- [ ] 双用途场景分别建档；口径变更回 P0 升版留痕。

## 回归判定规则

- 每条样例的断言必须逐条通过；
- 出现臆造信息、越界产物、默认授权、跳过停止分支任一情况，判不通过；
- 样例可扩展，但正向与护栏两类不可省略。
