# 第二步 · 选段方案（P1）字段契约与判定规则

> 配套 `assets/prompt-p1-selection.md`（v1.7）。本文件定义结构单字段、角色枚举、判定标准、确认环节规则与校验项，供 Skill 实现与测评核对使用。要素通俗名对照见 SKILL 总纲对照表。

## 1. 输入前置条件

| 输入 | 来源 | 缺失处理 |
|---|---|---|
| P0 成片需求单 | 已封存 v1 | 无需求单不进入 P1 |
| B1 成片目标与时长 | 需求单 B1 | 目标区间缺失不进入 P1 |
| B2 目标观众 | 需求单 B2 | 口径不明时不按对外片处理 |
| B3 期望动作 | 需求单 B3 | 落点方向缺失时只做主题呈现 |
| B4 平台画幅 | 需求单 B4 | 本节点不构图，但记录画幅约束 |
| 带时间码转写稿 | 主素材转写 | 无转写稿先完成转写；不清段落标待核；无说话人分离先标注限制 |
| D1 保留清单 | 需求单 | 逐项定位，找不到列入待核 |
| D2 禁区清单 | 需求单 | 无禁区则按「无」执行，仍逐段复核 |
| A5-1/A5-2 授权状态 | 需求单 | 未授权/仅限内部的人物与素材不入选对外片 |
| A5-3 配乐偏好 | 需求单 | 曲风/人声形态偏好带入 P3；本节点不生成垫乐 |

## 2. 裁决顺序

需求单已确认口径 > 用户当轮明确补充 > 历史物料 > 模型推测。冲突项列入待确认，不按素材现状改写需求口径。

## 3. 转写字段结构

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| start_time | 秒 | 是 | 语音边界起始时间 |
| end_time | 秒 | 是 | 语音边界结束时间 |
| speaker_id | 文本 | 否 | ASR 编号（sp1…）；轻口径无此字段，不等于真实姓名 |
| speaker_role | 枚举 | 是 | 主讲人 / 嘉宾 / 观众 / 不明；无编号时按上下文推定 |
| text | 文本 | 是 | 识别文本 |
| confidence | 0–1 | 否 | 置信度；轻口径无此字段；只作核对依据，不进对外结构单正文 |

## 4. 转写质量分级

| 等级 | 条件 | 处置 |
|---|---|---|
| 可用 | confidence ≥ 0.8 | 可作选段依据，摘要可引用 |
| 语境不通误识 | confidence ≥ 0.8，但文本与主题/上下文语义不合（名词不存在、整句断裂、音近错配） | 不按高置信放行；标待核，二次识别 + 上下文比对；两次仍不通或证据不足则降格，摘要/字幕不照抄原短语，只留可佐证的保守表述，风险清单登记原误识与处置 |
| 待核 | confidence < 0.8 | 不单独作为入选依据；由 AI 局部重识别或上下文复核后再定，仍存疑不入选 |
| 关键复核 | D1 金句、点名人物、头衔、俱乐部/活动名 | 由 AI 二次识别与上下文比对复核原话；两次一致按识别取值，冲突取保守表述 |
| 无置信度（轻口径） | 结果不含 confidence 字段 | 不做自动分级；通读标记语句不通、专名存疑、听不清的片段为待核，由 AI 二次识别或上下文比对复核 |
| 暂停 P1 | 语句不通占比过高、说话人完全无法区分、缺失覆盖主干 | 回 P0 补转写或缩小选段范围，不出结构单 |

## 5. 转写预处理

1. 覆盖核对：转写首末时间码比对原片时长；未覆盖段标「转写缺失」，不推断内容、不当作无发言。
2. 术语校准：命中 D3 误写时摘要改回正确写法，备注原误写；未收录专名标待核。
3. 碎片合并：<1.2 秒笑声/附和/语气词并入相邻段或互动备注，不单独成段。
4. 风险清单：低置信、语境不通误识、说话人不明、转写缺失、术语待核单列。

## 6. 结构单字段定义

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 成片序号 | 整数 | 是 | 按成片呈现顺序排列 |
| 原片顺序号 | 整数 | 是 | 该段在原片中的先后；主干段递增 |
| 起止时间码 | 时间区间 | 是 | `MM:SS–MM:SS`，以主素材为准；辅助片段注明来源 |
| ASR 编号 | 文本 | 否 | 转写稿 speaker_id；轻口径无此字段时留空 |
| 推定身份 | 枚举/文本 | 是 | 主讲人 / 嘉宾 / 观众 / 不明；不明标「观众」 |
| 主线环节 | 枚举 | 是 | 开场钩子 / 问题提出 / 论点展开 / 案例佐证 / 情绪点缀 / 收尾落点 |
| 主角色 | 枚举 | 是 | 钩子 / 主干 / 金句 / 笑点 / 互动 / 落点 |
| 副角色 | 枚举/空 | 否 | 金句 / 笑点 / 互动；一段最多一个副角色 |
| 内容摘要 | 文本 | 是 | 一句话概括，不照抄长段；术语已校准 |
| 保留理由 | 文本 | 是 | D1 指定项或对应保留标准编号；注明主线承接与首尾呼应关系；标明该段承担论点 / 例证 / 落点环节 |
| 对目标观众的作用 | 文本 | 是 | 说明观众为何能懂、为何有效 |
| 证据来源 | 枚举 | 是 | 文字可证 / 需画面核验 / 需音频核验 |
| 备注 | 文本 | 否 | 口径待改 / 转写待核 / 低置信 / D1 指定项 / 授权待核 / 术语待核 / 轻口径无编号 / 重口径分离失败 / 动作峰值待补帧 |

## 7. 说话人映射与归属

- ASR 编号与真实姓名分离；有编号时编号与身份双登记；轻口径无编号字段时，按上下文直接推定身份，不编造编号。
- 主讲人为开场主讲者，其余结合上下文推定；无法推定记「观众」。
- 同编号内笑声、附和与发言拆开：发言归角色，笑声掌声计入互动备注。
- 主讲人复述观众或引用旧案例，归属原说话人；被引用但未现场发言者不进说话人表。

## 8. 段落粒度

- 单段建议 15–60 秒；完整论点不拆半，相邻不同观点必须分段；
- 换人讲话断段；提问与回答分别成段；
- 剔除段不与保留段合并；入选段内不夹带整句剔除内容；
- 同一完整案例的相邻两段（如同一学员故事的前后半场）可合并为一段控制时长；合并后重新登记主/副角色、净时长与身份归属；是否合并列入 P1 闸口待确认，不在 P2 擅自并段；
- 多素材时先定基准素材，辅助片段单列并注明来源；段序按需求单核定的场次顺序，不按文件名推断；各段独立时间码，段间空档不补造承接句。

### 8.1 段落自足性（论点—论证—落点）

- 每段脱离相邻段后，观众能听懂这段想说的一个观点；成分分论点句（主张/判断）、论证/例证（案例/对比/画面/数据）、落点句（例证收束回主张的结论）。
- 禁止只提取例证、对比画面、奇观或金句而剥离所属论点：一段只交代「发生了什么」而没有「由此说明什么」，判为不自足，不得单独成段。
- 不自足处置：回补论点铺垫句或落点结论句；论点与例证在原片上分处两段时，按同论点合并规则归并，保留「铺垫—例证—落点」完整链条；合并后超时长只给压缩建议，不在段内砍掉论点句或落点句。
- 整段仅为例证时，保留理由登记其所属主张落在前置还是后置段，并随合并规则归并；互动反应依附相邻主干段，不按独立观点段处理。
- 互动/案例段须交代发起该互动的论点目的（请某人上台、引出例子佐证哪条主张）；只留故事或反应、不讲目的的，判不自足，回补目的句或并入相邻主干段。
- 互动案例段区分论点目的句、核心冲突/例证、落点结论；过程性排练指导、引导来回、无效起哄与试错过程压缩或剔除；压缩不得砍掉目的句、核心冲突与落点句。

## 9. 角色枚举与边界

| 角色 | 边界 | 禁止情形 |
|---|---|---|
| 钩子 | 开场抓注意力的原话或场面 | 不得用问候、感谢、自我介绍开场 |
| 主干 | 支撑主题的核心讲解，按原片顺序递进 | 不打乱叙事递进 |
| 金句 | 脱离上下文可独立成立的短句 | 需背景知识才懂的观点不入金句 |
| 笑点 | 肢体、扮丑、反差趣味 | 不保留冒犯性、内部梗笑点；转写无法佐证的肢体动作标需画面核验，语调起伏与现场反应标需音频核验 |
| 互动 | 真实观众反应 | 不把观众闲聊当主干 |
| 落点 | 收尾观点或态度 | 必须取自原片；不加需求单之外的报名引导；不自行撰写收尾 |

- 肢体动作峰值可能落在转写句点之外（动作起势/顶点/回落不与某句台词对齐）；此类段备注标「动作峰值待补帧」，交 P2 在动作区间内取起势/峰值/回落多张或短片段，不只锚定台词句点抽帧。
- 一段可有一个主角色、一个副角色，不重复计段；
- 观众段只留推动讲解、制造真实反应或 D1 指定互动；单纯附和、笑声、闲聊不入主干；
- 提问归互动，回答归主干。

### 主线环节与连贯
- 每段归入一个主线环节：开场钩子 / 问题提出 / 论点展开 / 案例佐证 / 情绪点缀 / 收尾落点；
- 金句、笑点、互动作情绪点缀，依附相邻主干段，不独立悬浮成跳点；
- 同一论点的段落相邻排列，其他论点不插入打断；论点先后保持原片递进；
- 开场钩子抛出的问题或矛盾，收尾落点须回应；呼应关系写入保留理由，脱节列待确认。

## 10. D1 原话一致性核对

| 一致性结论 | 处置 |
|---|---|
| 吻合 | 登记转写写法与时间码 |
| 措辞不符 | 记录需求单写法、转写写法；AI 二次识别 + 上下文比对，两次一致按识别取值，冲突取保守表述；不照搬转写，不擅改需求单；记入风险清单 |
| 未定位 | 列保留项待核，不编造时间码与原话 |

## 11. 保留与剔除规则

### D1 指定（强制保留）
D1 金句、肢体笑点、互动默认强制保留；仅当落在 D2 禁区或授权不明/未授权时才可剔除，并在保留项核对表标「未能保留」，注明剔除原因与对成片目标的影响，列入待确认。D1 项不参与「两条以上」门槛；措辞不符按第 10 节处理。

### 其余保留（满足两条以上）
1. 反转、反常识、具体细节；
2. 脱离上下文可懂、可独立成立；
3. 有情绪、画面感或真实互动；
4. 主题主干不可缺少。

### 一律剔除
- 问候、报幕、感谢、自我介绍、角色感谢；
- 口头禅、语气词、重复、纯流程报幕过渡；承上启下的因果/转折/对比承接句保留，删掉会断逻辑的话题衔接不按废话剔除；
- 跑题闲聊、无关铺垫；
- D2 禁区人物、段落、信息；
- 转写不清、说话人不明、授权不明段落；
- A5 未授权/仅限内部的人物发言与画面素材。

## 12. 时长与容量规则

- P1 计入选段净时长：口播段按说话时长，互动段（提问、附和、笑声、鼓掌留白）按该段时间码跨度计入；不含转场、字幕停留、首尾片包装；
- 目标区间取自需求单 B1；本节点只估算，不更改目标；
- 密度参考：5–7 分钟主片约 8–14 段，仅参考不作硬门槛；
- 超出区间给减段建议；不足区间给补段方向；均由用户确认；
- 成片密度不足时优先减段数，不靠拉长每段凑时长。
- 超区间或不足区间挂账闭环：未拍板前不在结构单上把差额抹平；登记归属节点（回 P1 减段/补段）与截止节点（P2 出粗样前）；用户确认放宽 B1 区间的，回 P0 改口径留痕，不在 P1–P4 口头放时长；闭环结论（减段、补段或放宽区间）记入结构单，未闭账不得进 P2。

## 13. 口径与授权确认环节

- B2=外部陌生人时，候选段出现内部称呼、行话、内部梗 → 标「口径待改」，不直接选入；内部观众记录口径豁免；
- 转写不清或说话人不明 → 标「转写待核」，由 AI 二次识别或上下文复核，仍存疑不入选，不派人工听辨；
- A5 未授权/仅限内部 → 剔除，原因标「授权不足」；
- 需求单与素材冲突 → 列入待确认，按第 2 节裁决顺序处理。

## 14. 时间码校验

- 起 < 止；段间不重叠、不漏接；
- 每条时间码可在转写稿对应到文本；
- 偏移、重叠、对不上 → 标「转写待核」，不凭推测修正；
- 同一锚点在转写稿与二次识别/理解模型返回的时间码不一致时，并列两个来源与各自时间码，AI 回该区间交叉复核定位；仍不一致则该段挂「待核」，不按任一来源写死时间码，复核结论记入风险清单；
- P1 时间码为语音边界参考，P2 截取前后留 0.3–0.5 秒余量。

## 15. 第二步（P1）完成判定（人工确认环节）

结构单必须满足：
- [ ] 每条入选段双序号、时间码、推定身份、主线环节、主角色、理由、观众作用、证据来源齐全；ASR 编号可选，轻口径留空；
- [ ] D1 逐项有归属与一致性结论；D2 全部排除；授权不足段已剔除；
- [ ] 主干保持原片递进顺序；同论点段落相邻；首尾呼应；副角色未重复计段；
- [ ] 每段论点—论证—落点齐备；例证/对比/奇观段未剥离所属论点；不自足段已回补论点/落点或按同论点合并归并；
- [ ] 时间码通过起 < 止、不重叠、可核对校验；风险清单无遗漏；
- [ ] 落点取自原片；未自造收尾观点；
- [ ] 预估净时长落在目标区间或给出调整建议；
- [ ] 待确认项带影响环节与截止节点；
- [ ] 无画面拼接、字幕、配乐、首尾片产物。

用户确认结构单后，才进入 P2 粗样；未确认不拼接画面。

### 15.2 档位裁剪（按 F0）

| 结构单字段 | L1 内部回顾 | L2 对外宣传 | L3 正式招募 |
|---|---|---|---|
| 成片序号、时间码、推定身份、主角色、保留理由、观众作用 | 登 | 登 | 登 |
| 副角色、ASR 编号、证据来源 | 从简，可只标需核验项 | 按 §6 全登 | 按 §6 全登 |
| 证据等级（文字可证/需画面核验/需音频核验） | 待核项标注即可 | 逐段登记 | 逐项登记，证据来源与回写可追溯 |
| 授权状态备注 | 仅记本人内部使用同意 | 按主体逐项登记 | 按主体逐项登记；`未确认` 主体不入选 |

- 三档共同底线不变：段落自足性、D2 禁区剔除、时间码可核对、落点取自原片、不自造收尾，不因 L1 从简免除。
- L3 入选段须在备注标明对应授权状态与证据等级；授权存疑段回 P0 补核，不在结构单里默认放行。

### 15.1 确认环节引导形态

- 结构单整体确认与待确认项拍板，沿用全局选项卡对话框形态：单值互斥出单选、可叠加出多选，卡片含选项、客观默认、不填影响环节与兜底「其他（自填）」；仅事实性补充走自由文本。
- 不把方案复核做成逐格手填的表格；语音与画面存疑由 AI 自核，不进闸口对话框。
