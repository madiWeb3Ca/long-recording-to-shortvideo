# 第五步 · 金句切片（P4）测试样例与判定规则

> 用于 P4 节点回归测评。每条样例给出输入情形、期望输出与断言；断言全部通过才算 P4 合格。授权、脱敏、术语、字幕与配乐口径沿用 P0–P3 封存结论。

## 样例 1：正向派生独立金句切片

**输入**：主片已定稿；D1 保留清单中有一段自问自答金句，源时间码可定位，主讲与出镜观众授权齐备，目标平台竖屏。

**期望输出**：派生一片 60–90 秒金句切片；自带开场看点、论点与落点；构图沿用主片安全区；授权、术语、字幕、配乐口径沿用主片；切片清单与包装记录字段完整。

**断言**
- [ ] 切片时长在 60–90 秒区间内；
- [ ] 开场看点、论点、落点齐备，不看主片可懂；
- [ ] 选题来自 D1 保留清单或已确认结构单；
- [ ] 切片清单登记源时间码、时长、独立成立结论与授权核对；
- [ ] 切片整体确认与选题取舍走选项卡对话框，未生成逐格手填表格。

## 样例 2：主片未定稿不派生（护栏）

**输入**：P3 主片仍是草案预览或待确认状态，包装未过人工闸口。

**期望输出**：暂停 P4，回 P3 先定主片；不在未定稿主片上切片段、叠标题或配切片配乐。

**断言**
- [ ] 未在主片未定稿状态下派生切片；
- [ ] 回退节点写明 P3；
- [ ] 草案预览未被当作切片输入归档。

## 样例 3：未核验/存疑段不作选题（护栏）

**输入**：结构单中有一段主片阶段已降格留痕、语义不通；另有一段核验结论缺失、时间码取不到。

**期望输出**：两段均不进切片清单；降格段沿用 P2/P3 留痕结论，缺失段挂待核；不在切片里复活存疑内容。

**断言**
- [ ] 降格短语与存疑段未进切片；
- [ ] 核验缺失段挂待核，未凭印象取材；
- [ ] 留痕项在切片记录可追溯。

## 样例 4：时长不足回补或合并（护栏）

**输入**：一个笑点片段素材仅约 35 秒，同一主题下另有相邻的反应与补充论点段。

**期望输出**：回补同主题论点/落点，或与同主题段落合并到 60 秒以上；不灌水拉长、不拼接无关内容凑时长。

**断言**
- [ ] 未用闲聊铺垫或无关片段凑时长；
- [ ] 合并段属同一主题，论点连贯；
- [ ] 不足时长的处置（回补/合并/撤下）写入记录。

## 样例 5：超出 90 秒给拆片建议（护栏）

**输入**：一段完整观点链素材约 110 秒，内含两个可分开的论点与一次独立反应。

**期望输出**：不压缩到丢失论证；按论点/反应切点给拆片建议；是否拆分由人工闸口确认，不在 P4 擅自硬剪。

**断言**
- [ ] 未为压进 90 秒而删断完整论证；
- [ ] 拆片切点按论点或反应边界给出；
- [ ] 超时长结论与建议记入切片清单备注。

## 样例 6：脱离上下文可懂，指代补交代（护栏）

**输入**：切片开场直接出现片内人物的内部称呼与场合缩写，观众未看过主片；该称呼在主片上下文里才有解释。

**期望输出**：在字幕或片内补一句可懂交代；悬浮指代不留给切片观众；不保留只有主片才成立的承接句。

**断言**
- [ ] 人物、场合背景有可懂概括交代；
- [ ] 开场不接主片上文，结尾不依赖主片下文；
- [ ] 未把内部称呼、缩写原样留给外部观众。

## 样例 7：未授权主体不进切片（护栏）

**输入**：某出镜观众在主片中授权状态为未确认；该观众恰好出现在拟选互动切片内。

**期望输出**：对应主体画面剔除或挂风险；未确认项不进入可发布切片，列入回退清单；不因单独分发放宽授权。

**断言**
- [ ] 未授权主体未进切片；
- [ ] 剔除或挂风险结论记入回退清单；
- [ ] 未把未确认状态当作已授权放行。

## 样例 8：术语按 D3 纠正（护栏）

**输入**：切片字幕草稿出现机构名、人名、活动英文名的误写（大小写、连写、用字错误）。

**期望输出**：按 D3 写法表逐条纠正；旧版弃用表述不上切片；无对应正确写法的臆造称谓不上片。

**断言**
- [ ] 机构名、人名、英文术语连写与大小写符合 D3；
- [ ] 未保留旧版弃用表述；
- [ ] 术语核对结果写入字幕沿用项。

## 样例 9：对外脱敏沿用主片口径（护栏）

**输入**：拟选切片含内部称呼、例会行话或内部梗；原片语音与画面在主片中按原片保留。

**期望输出**：字幕与包装层做对外化清理；不替换原片语音、不回删画面段落；清理记录对应到切片段落。

**断言**
- [ ] 字幕层无内部称呼、行话、内部梗；
- [ ] 未在 P4 回删该段画面；
- [ ] 清理动作对应到具体切片段落可追溯。

## 样例 10：配乐沿用主片口径且人声优先（护栏）

**输入**：切片需要垫乐；生成提示词拟用带歌词伴唱；切片对白密集。

**期望输出**：沿用 A5-3 口径，由 AI 音频生成工具自创纯音乐垫乐，不走曲库；带歌词人声曲不压主讲；生成提示词、曲风、配器与人声形态登记，电平低于人声。

**断言**
- [ ] 未用人声歌词曲压切片主讲；
- [ ] BGM 未盖过对话与笑声反应；
- [ ] 生成提示词、曲风、配器与人声形态已登记。

## 样例 11：切片独立取材，不在主片上硬裁（护栏）

**输入**：拟把主片结尾一刀切下作为单独切片；该结尾依赖主片前文才成立。

**期望输出**：切片从母带/已核验素材按选题独立取材；依赖主片上下文的结尾不单独成切片；记录取材来源与时间码。

**断言**
- [ ] 未把主片硬裁片段直接当独立切片；
- [ ] 切片时间码取自母带或已核验素材并可对照；
- [ ] 依赖上下文的承接段未单独成片。

## 样例 12：标题封面不夸大、不剧透、不催单（护栏）

**输入**：拟为切片加标题板与封面；封存 C3-模式=`无板`、C3 为空；另有其他切片的落点可在本片标题里预告。

**期望输出**：标题只概括本切片实际内容；不写「必火」「爆了」类诱导表述，不剧透其他切片落点；不加报名催单与留资入口、不放联系方式。

**断言**
- [ ] 标题未夸大、未使用传播承诺类诱导表述；
- [ ] 未剧透其他切片落点；
- [ ] 无催单、留资入口与可识别联系方式。

## 样例 13：身份未推定的互动不单独成片（护栏）

**输入**：一段主讲与观众互动，观众说话人编号缺失、身份未推定；问答反应完整但对面身份不明。

**期望输出**：该互动段不单独成片；互动切片只保留双方身份已登记的互动；身份问题回 P1 补推定后再判。

**断言**
- [ ] 身份未推定的互动未进入切片清单；
- [ ] 身份归属问题回退到 P1；
- [ ] 未在字幕里臆测对面身份或编号。

## 样例 14：产物完整性自检

**输入**：切片派生与包装完成，待移交人工闸口。

**期望输出**：每片整段解码无错误；抽查开场、落点、动作峰值与字幕帧非黑屏、主体字幕在位；时长在目标区间；无叠双字幕；画幅、帧率、音轨参数登记完整。

**断言**
- [ ] 每片可正常解码，无报错；
- [ ] 抽查帧非黑屏、主体与字幕在位；
- [ ] 实测时长与目标区间对照一致；
- [ ] 未出现叠双字幕；自检结果记入切片包装记录。

## 样例 15：口径待改段不作切片选题（护栏）

**输入**：一段在主片中标注为口径待改、内部化表述较重的段落，笑点效果较好。

**期望输出**：该段不作为切片选题；口径问题回 P3 口径层复核；不把内部化内容单独对外分发。

**断言**
- [ ] 口径待改段未进切片清单；
- [ ] 口径问题回退到 P3 复核；
- [ ] 待复核项带归属节点与截止节点。

## 样例 16：板位按封存 C3-模式 执行（正向 + 护栏）

**输入**：封存需求单 C3-模式=`标题板+尾片`，C3 标题文案已定稿；C2 片尾组织名、引导语已核定；另有一片拟用同批切片标题。

**期望输出**：
- 该片按封存方式加标题板与切片尾片；标题逐字取自 C3，尾片组织标识与引导语沿用 C2，不另拟口号；
- `无板`/`标题板` 模式下不生成尾片；板位排版问题回 P3；
- 未把其他切片标题或落点搬进本片板位。

**断言**
- [ ] 板位方式与封存 C3-模式 一致；
- [ ] 标题逐字取自 C3，未由节点自行拟写；
- [ ] 标题板字号达可读下限、文字在安全边距内不贴边溢出、停留可读，未缩字硬塞；
- [ ] 切片尾片沿用 C2 口径，无催单、留资与联系方式；
- [ ] 未剧透其他切片落点，未套用其他切片标题。

## 样例 17：未定稿主片只出预览样片（护栏）

**输入**：主片仍是待确认包装样片，遗留底板构图、字幕大小等待复核项；用户想先看两条切片方向。

**期望输出**：常规应回 P3 先定主片；确需先看方向时，只出「切片预览样片」，显式标注未定稿、不标可发布终版、不进发布闸口；主片定稿后按同一时间码重跑，不直接沿用预览样片。

**断言**
- [ ] 预览样片显式标注未定稿状态，未冒充可发布终版；
- [ ] 未在未定稿主片上派生正式切片清单；
- [ ] 遗留闸口项随样片登记，未声称构图字幕已终审。

## 样例 18：段证据等级登记，未核验声音事件不强化（护栏）

**输入**：一条观众互动切片含掌声与应答笑声；对应段落仅有文字转写，未做音频核验；观众授权状态已登记。

**期望输出**：段证据等级登记为 `文字可证`；掌声/笑声等声音事件标未独立核验，不强化为反应高点，不据此把该段定为笑点选题；声音事件核验回 P1/P2 补核后再判。

**断言**
- [ ] 每段证据等级与 P1/P2 核验记录一致；
- [ ] 未核验声音事件未写成卖点或反应高点；
- [ ] 核验缺口挂回退节点与截止节点。

## 样例 19：超时拆片后重新独立判定（闭环）

**输入**：一条互动链全链约 100 秒，超出 90 秒上限，含论点一与论点二两个可分开的论点。

**期望输出**：不硬压时长；按论点给拆片建议，拆出的两条新片各自重新走选题定位与独立成立判定（钩子—论点—落点、指代可懂、授权核对），不按原链直接分段交付。

**断言**
- [ ] 未压缩到丢失完整论证；
- [ ] 拆出的各新片分别做独立成立判定并登记结论；
- [ ] 拆片选题仍取自已核验素材，时间码可对照。

## 样例 20：无配乐样片标注与备选标题边界（正向 + 护栏）

**输入**：AI 生成失败或暂未生成垫乐，切片暂未配 BGM；P4 备了两个工作标题，但封存 C3-模式=`无板`、C3 为空。

**期望输出**：配乐状态标「无配乐样片」，人声电平单独复核，不冒充可发布终版；备选工作标题只记入备注，不上板段；板位按封存 `无板` 执行。

**断言**
- [ ] 无配乐状态显式标注，人声完整性已复核；
- [ ] 备选标题未进板段、未冒充封存文案；
- [ ] 板位与封存 C3-模式 一致；
- [ ] 未自行拟写口号、组织名等品牌信息。
