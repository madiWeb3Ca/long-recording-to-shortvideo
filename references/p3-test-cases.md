# 第四步 · 包装成片（P3）测试样例与判定规则

> 用于 P3 节点回归测评。每条样例给出输入情形、期望输出与断言；断言全部通过才算 P3 合格。文案、术语与授权口径以封存需求单为准。

## 样例 1：正向包装（主片 9:16）

**输入**：已确认粗样，C1-模式=`默认片头`、C2-模式=`默认尾片`，C1/C2/D3/A6/A5-3 齐备，主讲人、出镜嘉宾、观众与画面素材授权齐备；目标平台小红书竖屏。

**期望输出**：产出 9:16 第一版正式片；主体居中偏上、在安全区内；默认片头三行、默认片尾四项齐全；字幕沿用或重压方案登记；配乐人声优先；包装记录字段完整。

**断言**
- [ ] 成片为目标画幅，未拉伸变形；
- [ ] 构图主体不出框，关键动作与多人同框完整；
- [ ] 默认首尾片文案与 C1/C2 逐字一致；
- [ ] 配乐生成提示词、曲风已登记；
- [ ] 成片整体确认与包装方式取舍走选项卡对话框，未生成逐格手填表格。

## 样例 2：粗样未确认不进入（护栏）

**输入**：P2 仍是草案试跑预览，或粗样尚未经闸口确认。

**期望输出**：暂停 P3，回 P2 先定结构；不对草案做竖屏构图、叠字幕或配配乐。

**断言**
- [ ] 未在未确认状态下包装；
- [ ] 回退节点写明 P2；
- [ ] 草案预览未被当作包装输入归档。

## 样例 3：片头文案逐字核对

**输入**：C1 确认三行：活动名「活动名占位」、主标题「主标题占位」、身份行「主讲人｜头衔一 · 头衔二 · 头衔三」。

**期望输出**：片头三行全放，文字逐字一致；旧海报稿头衔、英文名、作废表述不出现在片头。

**断言**
- [ ] 活动名英文连写与大小写符合 D3；
- [ ] 三行头衔全部保留，无缺项；
- [ ] 未使用旧英文名、旧头衔等旧版弃用表述；
- [ ] 未自行改写主标题或另拟副标题。

## 样例 4：片尾不催单不留资（护栏）

**输入**：C2 含俱乐部全称、口号、引导语、场地；B3 期望动作为「了解主题」，外部观众。

**期望输出**：片尾只呈现 C2 四项；不出现报名按钮、留资入口、联系方式或促销话术；引导语仅导向更多工作坊内容。

**断言**
- [ ] 片尾无报名催单与留资入口；
- [ ] 无可识别联系方式；
- [ ] 引导语未改写为报名号召；
- [ ] 俱乐部全称与连写符合 D3。

## 样例 5：原字幕基本一致沿用（护栏）

**输入**：逐段比对，拟用字幕与原片烧录字幕在位置、字体颜色、断行上基本一致。

**期望输出**：沿用原字幕，不擦除、不重压；记录中标注该段为「沿用原字幕」。

**断言**
- [ ] 未叠出双字幕；
- [ ] 沿用结论逐条写入字幕清单；
- [ ] 未对原字幕做无必要的擦除重压。

## 样例 6：需重排字幕走擦除重压评估（护栏）

**输入**：竖屏构图后原烧录字幕位置被安全区挤压，或需要关键字放大、换颜色、重新断行。

**期望输出**：先评估擦除原字幕的可行性与残留风险，再重压；擦除方案、残留风险与重压样式记入记录，不在未评估前直接叠加重压字幕。

**断言**
- [ ] 重压前已记录擦除评估结论；
- [ ] 残留风险有说明；
- [ ] 未在保留原字幕的情况下叠加第二份字幕。

## 样例 7：竖屏构图保留动作与同框（护栏）

**输入**：一段单人主讲带大幅度手势；另一段为主讲与观众两人互动同框。

**期望输出**：构图不裁切手势与表情；多人段保留两人同框，副角色不被裁出画面；下沿道具杂物避让。

**断言**
- [ ] 主讲手势、动作峰值完整入框；
- [ ] 多人互动段两人同框保留；
- [ ] 下沿道具品牌露出未贴边压主体；
- [ ] 底板填充时上下底板占比均衡，前景垂直居中、未被压到一角；
- [ ] 动作被裁的段落已回退调整构图。

## 样例 8：降格短语与存疑词不上字幕（护栏）

**输入**：P1 留痕的两处语义不通降格短语；金句②冲突词与封存写法不一致；另有存疑动词未复核。

**期望输出**：降格短语不写成字幕；金句②取保守表述（省略存疑词或不写成字幕金句）；存疑动词不写成字幕，挂待核；原误识与处置在记录留痕。

**断言**
- [ ] 降格短语未进字幕；
- [ ] 冲突词未按未复核写法上片；
- [ ] 存疑动词未写成字幕判断；
- [ ] 留痕项在包装记录可追溯。

## 样例 9：术语误写纠正（护栏）

**输入**：原转写/字幕草稿出现机构名误写、课程英文名误写、人名误写、英文术语误写（大小写、连写、用字错误）。

**期望输出**：按 D3 纠正为机构名、课程名、人名、英文术语的正确写法；无对应正确写法的臆造称谓不上片。

**断言**
- [ ] 机构名大小写与连写纠正；
- [ ] 人名按 D3 正确写法；
- [ ] 英文术语连写与大小写纠正；
- [ ] 未保留旧版弃用表述。

## 样例 10：配乐人声优先且不压主讲

**输入**：生成提示词拟用带人声歌词伴唱；主讲对白密集。

**期望输出**：带歌词人声曲不压主讲；生成垫乐电平低于人声，有人声段落压低、间隙适度抬起；提示词、曲风、配器与人声形态登记。

**断言**
- [ ] 未用人声歌词曲压主讲；
- [ ] BGM 未盖过对话与笑声反应；
- [ ] 人声清晰度为主，配乐不抢戏；
- [ ] 生成提示词、曲风已登记。

## 样例 10A：AI 生成垫乐音轨质检

**输入**：P3 为内部回顾片生成一版纯音乐垫乐；工具返回一个音频文件，拟直接合入成片。

**期望输出**：合入前先过机检——容器编码实测可解码、时长对齐铺底区间、响度复测不削波、无异常静音与器乐突断；试听首/中/尾三点，气质贴合主题、无变调/突断/含糊/莫名念白合唱；候选附差异说明，不自评「好听」；生成曲信息与机检日志入包装记录。

**断言**
- [ ] 容器编码经实测可解码出声，未只凭后缀判断；
- [ ] 垫乐时长与铺底区间对齐，循环/分段接缝不断裂；
- [ ] 响度复测达标、max 未削波；不达标已校正复测或重生成；
- [ ] 首/中/尾三点已试听，无突变调、突断、含糊或莫名念白合唱；
- [ ] 候选附编曲/配器/气质差异说明，未写「已确认好听」；
- [ ] 生成曲 URL、时间、完整提示词与机检日志留档。

## 样例 11：内部口径清理（护栏）

**输入**：一段含内部称呼、例会行话或内部梗的口径待改段，按原片保留语音画面。

**期望输出**：字幕与包装文案层做对外化清理；不替换原片语音、不回删画面段落；清理记录对应到段落。

**断言**
- [ ] 字幕层无内部称呼、行话、内部梗；
- [ ] 未在 P3 回删该段画面；
- [ ] 清理动作对应到具体段落可追溯。

## 样例 12：未授权主体剔除（护栏）

**输入**：某出镜观众授权状态为未确认。

**期望输出**：对应主体画面剔除或挂风险；未确认项不进入可发布状态，列入回退清单。

**断言**
- [ ] 未授权主体未进成片；
- [ ] 剔除或挂风险结论记入回退清单；
- [ ] 未把未确认状态当作已授权放行。

## 样例 13：口号待复核标注（护栏）

**输入**：片尾口号为一条待品牌复核的俱乐部口号，未列入官方固定 slogan，本期确认沿用（R3）。

**期望输出**：按已确认文案上片，同时在包装记录标注「发布前待品牌复核」；不擅自替换口号，也不掩盖待复核状态。

**断言**
- [ ] 口号按确认文案上片；
- [ ] 已标注发布前品牌复核及截止节点；
- [ ] 未在 P3 自行更换口号。

## 样例 14：产物完整性自检

**输入**：包装合成完成，待移交人工闸口。

**期望输出**：成片整段解码无错误；抽查片头、片尾、衔接段与字幕峰值帧非黑屏、主体字幕正常；时长与粗样净时长对照一致；字幕无叠双份；参数登记完整。

**断言**
- [ ] 成片可正常解码，无报错；
- [ ] 抽查帧非黑屏、主体与字幕在位；
- [ ] 时长对照粗样净时长，差值在余量范围内；
- [ ] 未出现叠双字幕；自检结果记入包装记录。

## 样例 15：片尾品牌 logo 选填（正向 + 护栏）

**输入**：品牌资产库提供总会标识与俱乐部标识（透明底正式文件），片尾为深色底；另一候选标识仅有视频截图、授权状态未核实。

**期望输出**：两枚合规 logo 横向并排、基线对齐、用反白版，不改色、不拉伸、不重排、不压 C2 文案；截图候选不使用；素材缺失或授权存疑的标识位留空，不从视频帧截取翻拍。

**断言**
- [ ] 仅使用规范授权文件，未从视频帧或海报照片截取；
- [ ] 深色底使用反白/白色版，未自行改色、拉伸或重排；
- [ ] 多枚 logo 并排对齐、间距一致，未压住片尾文字；
- [ ] 素材缺失或授权存疑时该位留空，未补造标识；
- [ ] 每枚 logo 的名称、来源文件、版本与授权状态已登记进包装记录。

## 样例 16：板上文字字号可读（手机竖屏）

**输入**：首尾板初版沿用默认小字号，主标题与场地地址在手机端观看吃力。

**期望输出**：按可读下限分档放大字号；超宽一行先拆行，不靠缩字硬塞；文字留在左右安全边距内，深底浅字对比清晰。

**断言**
- [ ] 主标题/品牌全称 ≥60px，口号/身份行 ≥40px，辅助信息 ≥30px（1080 宽画布）；
- [ ] 未靠缩字把超宽行强行塞进边距；
- [ ] 文字在安全边距内不贴边、不溢出，深浅底字色对比可读。

## 样例 17：曲风与人声形态自主判定

**输入**：进入配乐阶段，封存需求单未指定曲风，也未说明要纯音乐还是人声伴唱。

**期望输出**：工作流按片情自主判定曲风（轻快欢快 / 舒缓 / 动感节奏 / 氛围纯音乐）与人声形态（纯音乐 / 男声伴唱 / 女声伴唱）；未判定前走兜底默认（纯音乐、轻快氛围）并登记；不擅自上男声或女声伴唱。

**断言**
- [ ] 曲风与人声形态按片情自主判定，记录在案；
- [ ] 未指定时兜底纯音乐，曲风与人声形态在记录中标注；
- [ ] 带歌词人声曲不压主讲，配乐电平低于人声。

## 样例 18：首尾板版式与音轨一致性

**输入**：首片尾片初版，片头用兜底灰蓝、片尾用品牌深藏青，两套底色；板段静音音轨采样率与主片不一致；片头停留 2s 偏短，需求单未定值。

**期望输出**：首尾底色同片统一（有品牌色用品牌色，无规范用同一兜底深色）；板段静音音轨参数与主片一致；停留达到可读下限（片头 ≥3s、片尾 ≥4s），未定值登记待确认；版本与变更记入版本记录。

**断言**
- [ ] 首尾板底色同片一致，未一头一尾两套底色；
- [ ] 板段静音音轨采样率、声道与主片一致，拼接处无音轨断裂；
- [ ] 片头 ≥3s、片尾 ≥4s，未定值已登记待确认；
- [ ] 每版版本号、变更点与回退依据记入版本记录。

## 样例 19：首尾片方式分支（无片头 + 自备尾片模板）

**输入**：封存需求单 C1-模式=`无片头`，未提供 C1 片头文案；C2-模式=`自备尾片模板`，俱乐部提供尾片模板素材与既定版式；未指定默认方式外的其他偏好。

**期望输出**：不生成片头板，成片由主片直接起，不留片头静音段；片尾套用自备俱乐部模板，沿用其版式与文案结构，只做竖屏适配，不擅自改写模板文案；模板素材来源、版本与版式登记入包装记录；C1 片头文案免登记。

**断言**
- [ ] 成片无片头板，主片直接起，无片头静音段；
- [ ] 片尾为自备模板版式，未套用默认 C2 四行文案；
- [ ] 自备模板仅做竖屏适配，模板文案未被擅自改写；
- [ ] 模板素材来源、版本与版式登记入包装记录；
- [ ] 片尾无催单、无留资、无联系方式。

## 样例 20：首句导入片头（正向）

**输入**：封存需求单 C1-模式=`首句导入`，C1 为一行开场导入句；其余包装条件齐备。

**期望输出**：不生成独立片头板；主片开头约 5 秒叠加一行导入句（字幕条或开场口播导入），点出主题或受访人身份；停留以读完为准，不留片头静音段，不排活动名/主标题/身份行三行板；导入句逐字取自 C1。

**断言**
- [ ] 未生成独立片头板，无片头静音段；
- [ ] 开头约 5 秒叠加一行导入句，文案与 C1 逐字一致；
- [ ] 未排三行板，未自行另拟标题或身份行；
- [ ] 导入句停留以读完为准，未压到主片人声。

## 样例 21：L1 内部回顾轻包装（正向 + 护栏）

**输入**：F0=`L1 内部回顾`，已确认粗样；无核定品牌首尾板文案、无规范 logo 文件、未生成垫乐；主讲人本人同意内部使用。

**期望输出**：
- 可读字幕按字号下限重压，主体构图不出框；
- 可不出品牌首尾板，或仅一行极简主讲人/活动条；不放 logo；默认无 BGM，垫乐仅记内部试用、不做可商用登记；
- 内部称呼行话可保留，但他人隐私、禁录内容仍不上；无催单、留资、联系方式；
- 包装记录从简，不套用 L2 全套品牌台账。

**断言**
- [ ] L1 档品牌板、logo、正式配乐条目按 §3.1 免核，未阻塞出片；
- [ ] 字幕达可读下限，无叠双字幕；
- [ ] 隐私脱敏与不催单留资底线未因轻流程减免；
- [ ] 成片可解码、无黑屏破损；
- [ ] 未把 L1 内部试用垫乐登记为可商用正式生成曲。

## 样例 22：L3 正式招募包装闭合（正向 + 护栏）

**输入**：F0=`L3 正式招募`，已确认粗样；官方品牌规范已核定组织全称、slogan 与 logo 版本；人物与 PPT、照片授权逐项留档；AI 生成曲可商用授权待发布前最后核对；片尾有入会号召，但不留联系方式。

**期望输出**：
- 首尾板按核定品牌规范排版，logo 取自正式品牌文件，版本与授权状态登记入包装记录；
- D3 术语台账逐项核对，内部称呼、行话、内部梗全量清理；
- 生成曲可商用授权在发布前闭合并入复核台账；未闭合前成片只标「待发布前复核」；
- 复核台账登记复核项、状态、责任人、截止节点；授权、品牌、配乐、脱敏四项全闭后才标可发布。

**断言**
- [ ] 品牌全称、slogan、logo 按官方规范核定，未沿用旧海报稿或临时口述；
- [ ] 人物与画面素材逐项留档，未确认主体或素材未进片；
- [ ] 配乐可商用授权状态发布前闭合登记，未带未核授权上线；
- [ ] 复核台账字段齐全（复核项/状态/责任人/截止节点），任一项未闭不进可发布状态；
- [ ] 片尾号召不含留资入口与可识别联系方式。
